# 地下王都：课程设计起步稿

## 游戏方向

控制台文字冒险 + ASCII 状态面板 + 回合制战斗。玩家逐步探索沉没王都，收集三灾与天启四骑士相关线索，调查王都沉没的真相。

## 首版范围

先实现一段可完整游玩的短流程：营地查看状态 → 进入遗迹 → 遭遇一种怪物 → 选择行动并结算战斗 → 胜利后获得奖励 → 返回营地。首版先用一个怪物和一种药水跑通流程，再由你扩充到任务书要求的三种怪物、装备商店、升级和存档。

## 建议的实现顺序

1. 先自己写菜单输入循环，并处理非法输入。
2. 定义角色数据和状态显示；确定 HP 降到 0 时的规则。
3. 写一次玩家行动与怪物行动，加入随机伤害和暴击。
4. 把角色抽象成基类，再让玩家和不同怪物通过虚函数表现行为差异。
5. 加入物品、背包、商店及任务书要求的运算符重载。
6. 最后加入升级、文件存档读档，并记录边界测试结果。

## 设计提醒

- 故事里的雪灾、地震、火灾和四骑士可以先作为遗迹线索与首领主题；先不急着决定它们是否真实存在，保留调查过程中的反转空间。
- 代码实现以课程要求为准：控制台可以只用字符画，不需要图形库。
- 每完成一个小步骤，先自行编译运行，再把遇到的问题和解决过程记进报告。
