# 《沉没王都》随机人物事件

> 状态：设计稿，2026-11-19
>
> 用途：在日常活动中插入短剧情，让地面枢纽、营地、酒馆和往返路程不只是菜单。

## 一、设计目标

- 事件短小，一次事件控制在 1—3 个画面内，不打断主线节奏。
- 事件不是纯随机奖励或惩罚，而是带选择的短剧：玩家可能帮对人，也可能被骗、被背叛。
- 事件可以有即时结果，也可以留下延迟后果：NPC 再次出现、传闻变化、伏击、见闻条目、商店价格变化等。
- 不要求每个事件都影响主线；但重要事件应写入 `story_progress.sav` 的标记，避免读档后重复或丢失。

## 二、触发方式

可插入的日常活动：

- 在地面枢纽左右移动、进入或离开城门 / 商店 / 营地 / 酒馆时。
- 在营地休息、与灰袍幸存者交谈、从遗迹返回地面时。
- 在通道中走到安静通道、尸体、废弃营地等事件节点时。

建议规则：

- 每次日常行动后有较低概率触发，例如 8%—15%；连续触发之间有冷却。
- 同一次休息最多触发一次，避免连续弹事件。
- 主线关键节点、首次进入某区域、战斗结算后不触发，优先保证主线流畅。
- 事件分“一次性”和“可重复”两类；一次性事件用 `event.*` 标记，可重复事件用冷却和条件控制。

## 三、通用事件结构

每个随机人物事件建议包含：

1. **场景**：一句话说明时间、地点、人物状态。
2. **人物**：文字画或现有 Sprites 复用；没有立绘时用简短描述。
3. **请求 / 冲突**：NPC 提出请求，或玩家发现异常。
4. **选择**：至少 2 个选项，通常为帮助 / 拒绝 / 观察 / 试探。
5. **结果**：金币、物品、HP/MP、状态、见闻、NPC 关系、后续事件标记。
6. **延迟后果**（可选）：几回合后、下一次回城、下一次休息时再触发。

原则：

- 不要让玩家在完全没有任何提示的情况下被必杀。
- 背叛、诈骗可以有征兆，但不要一眼看穿；观察、试探、拒绝都是有效策略。
- 失败要有代价，但不应让玩家直接损失全部进度。

## 四、事件 1：帮助他人（可能是诈骗）

### 场景

灰烬街道的墙角、营地外或酒馆门口，一个受伤的人/老人/孩子向玩家求助。

### 请求

- “我被抢了，能不能给我一瓶红药水？”
- “我的同伴压在下面，能不能借我几枚金币？”
- “带我去城门，我走不动了。”

### 分支

- **直接帮助**
  - 真求助：获得少量金币、药水、见闻或旧物；NPC 可能记住玩家。
  - 诈骗：NPC 趁玩家靠近偷走金币/物品，或把玩家引到伏击点。
  - 也可能是“半真半假”：人确实受伤，但也在替别人试探玩家。
- **拒绝**
  - 安全离开；可能错过见闻或后续回报。
  - NPC 可能记恨，之后以敌对身份出现。
- **观察 / 试探**
  - 检查伤口、身份牌、脚印、同行者。
  - 可能识破诈骗，也可能因为多疑错过真正需要帮助的人。

### 结果建议

- 金币 5—20、红药水、旧王都小物件、见闻条目、NPC 好感/敌意标记。
- 诈骗事件可以触发一场小战斗或只损失少量金币，不要直接致命。

## 五、事件 2：组队申请（背叛杀害）

### 场景

营地、酒馆或遗迹入口，一个落魄佣兵 / 考古助手 / 流民请求与玩家同行。

### 请求

- “我熟悉下面，带我一程，战利品对半分。”
- “我在找失散的同伴，能不能跟你走一段？”
- “我不要钱，只想活着出去。”

### 分支

- **接受**
  - NPC 暂时同行；在低 HP、发现宝物、下一层入口、返回地面时可能背叛。
  - 背叛可能是抢走战利品、把玩家引向怪物、或在背后动手。
  - 如果玩家给足报酬、救过 NPC、或提前识破，可以避免背叛。
- **拒绝**
  - NPC 离开；之后可能在别处成为敌人、尸体或商人。
- **试探**
  - 问来历、检查装备、故意走危险路线；可能提前发现破绽。

### 设计注意

- 背叛不能是纯粹的“随机必死”；应有可观察的征兆，例如：
  - NPC 对某件战利品异常在意。
  - 身份牌是假的，或名字与传闻对不上。
  - 在低 HP 时频繁催促玩家继续深入。
- 玩家可以通过拒绝、分道、留一手、提前给报酬来降低风险。
- 背叛事件可以进入战斗，也可以只抢走物品后逃跑；根据玩家等级和剧情进度选择。
- 若 NPC 真的杀死玩家，应走正常战败流程，不要额外永久惩罚。

### 结果标记

- `event.party.accepted`
- `event.party.betrayed`
- `event.party.resolved`
- `npc.*.dead` / `npc.*.hostile` / `npc.*.friendly`

## 六、事件 3 及以后（略）

预留事件类型：

- 拾荒者兜售“旧王都宝贝”，可能是假货。
- 矿工/拾荒者出现矿石病症状，求助、被歧视或被隔离。
- 假门卫/假商人骗取身份牌。
- 传教士宣讲旧王或新国的“自古以来”。
- 赌徒、孩子、逃兵、寻找亲人的流民。
- 旧地旧民认出新国官修史书与口述历史的矛盾。

## 七、与矿石病、主线和其他系统的关系

- 矿石病可以作为随机事件的结果或事件主题：矿工咳出矿尘、拾荒者皮肤结晶、NPC 请求药。
- 组队背叛事件可以牵出矿石走私、旧王朝遗物或新国征兵。
- 帮助他人事件可以给见闻条目，但不要把所有事件都变成主线线索。
- 事件标记只保存关键状态，不保存每一次随机判定。
