# 现实风俗素材库·二十七：北美专题

> 状态：素材收集 v0.1，2026-11-26。
>
> 用途：按地区深挖北美风俗，每条给“具体地区/群体 + 做法 + 逻辑 + 可借 + 出处”。
>
> 说明：
> - 北美不是一个“文化”；美国南部/东北部/中西部/西海岸/加拿大/魁北克差异极大。
> - 原住民已在第十九卷单独处理；这一卷主要收移民/殖民/现代美国/加拿大。
> - 出处以历史研究/博物馆/UNESCO 为主；百科只当入口。
> - `【高】` = 学术来源较可靠；`【中】` = 来源较泛/地区差异大，写进游戏前再核；`【待核】` = 只当线索。
> - 涉及殖民/种族/暴力/贫困的内容，写作时不要猎奇；借制度逻辑，不借痛苦表面。

## 七、怎么用

1. **先看具体地区/群体**：不要写“美国人……”，写“美国南部/纽约/中西部/加州/魁北克……”。
2. **再看“谁在讲/谁受益”**：种族/阶级/移民/资本/国家都在改写这些风俗。
3. **借逻辑，不借表面**：牛仔→灰骑；66 号公路→炉路；diner→炉馆；县集市→炉会；硅谷→炉坊。
4. **标注可信度**：`【中】/【待核】` 的条目，写进游戏前再查。
5. **不要猎奇**：殖民/种族/贫困/灾难，背后是真实的人；写制度，不写“奇观”。
