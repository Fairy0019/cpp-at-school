## 一、古国的衰落

古国（旧国）疆域辽阔，但它的“辽阔”更接近松散的联盟与羁縻，而不是中央集权的帝国。旧王不是世袭皇帝，而是由各方推举、确认后治理；百姓对“谁坐在王座上”并没有强烈执念，只要税轻、路通、日子还能过，就承认这个王。

后来古国日益衰落：

- 灾害频繁，死伤无数，人口不断四散迁走。
- 中央对边地的控制越来越弱，很多地方实际上已经自行治理。
- 旧王最终离开。按现有设定，他是在停炉之后离开的；停炉并没有真正熄灭炉心，只是切断输出并重新封存。离开的具体原因、炉心与三灾的关系仍是暗线。
- 王离开后，旧地留下了三类人：不愿走的人、无处可去的流民、以及已经进入旧地的异邦人。

古国的衰落气质可以参考“一个辽阔但已经无力再治的旧帝国/联合体”，但不直接影射现实国家。

## 二、过渡政权与失序

旧王离开后，旧地没有立刻出现一个稳定的新王朝，而是进入过渡期。

1. **理想主义者接手**
   - 一群有政治理想、但缺乏实际治理能力的人组成过渡政权，自称“散人政府”。
   - 他们能写纲领、能开会，却控制不了地方、军队和粮食。

2. **异邦人投靠，佣兵自重**
   - 外来族群先以投靠者、劳工或佣兵的身份进入旧地。
   - 过渡政权依赖他们维持秩序，佣兵逐渐自重，不再完全听命。
   - 外部异邦趁机入侵，过渡政权不堪大用。

3. **民间自组织，实为土匪**
   - 在官府失灵、异邦入侵的真空里，民间（尤其是外来人）开始自组织。
   - 这些组织名义上反抗入侵、保护乡里，实际上很快土匪化。
   - 他们奉行“非友即敌”的二元逻辑：不追随者杀，追随者也要被编入、被奴役。
   - 旧的乡里秩序被进一步打碎，恐惧成为唯一的秩序。

4. **新国取代过渡**
   - 新国最终从过渡政权的废墟中崛起，由散人政府中的军阀、军功集团和本地豪强合流而成。
   - 它不是“恢复古国”，而是一个新的军事政权。

## 三、新国

新国建立后，自居古国的继承者：

- 它宣称旧国的辽阔疆域都是“自古以来的领土”，常以此对外征讨。
- 它需要旧国的合法性，却不需要旧国的推举传统。
- 官方史书把旧王写成暴君，把旧国写成一个人心离散的帝国；这样才能证明新国是“替天行道”的继承者。

但旧地的民间记忆不同：

- 旧民怀念旧王，尤其怀念“日子还能过”的那段时间。
- 旧国并不是一个帝国；旧王一直是被推举而治的。
- 人们并不关心谁治理，只关心生活是否正常。
- “暴君”是胜利者写下的版本，不完全可信。

新国王位共历 **四加七代，合计十一代**：

- 前四代与后七代的具体分界、君主事迹待补。
- 第十一代王无作为，新国最终亡国。
- 新国亡国后，旧地再次进入无主状态；地下遗迹与旧王朝的记忆仍留在原处。

## 四、三套历法

| 历法 | 起点 | 使用范围 | 备注 |
| --- | --- | --- | --- |
| 旧历 | 古国的纪年起点（待定） | 古国官方与旧地 | 止于旧王离开 |
| 残历 | 旧王离开当年 = 残历元年 | 旧地、流民、过渡政权、旧民 | 新国建立后仍被旧地和民间沿用 |
| 新历 | 新国建立当年 = 新历元年 | 新国官方 | 新国用于纪功、对外征讨和官修史书 |

换算关系：

- 旧历末年 = 残历元年。
- 设过渡期共 T 年，则新历元年 = 残历 T+1 年。
- 残历年份 = 新历年份 + T。
- T 的具体年数、旧历的绝对年份、新历十一代各自的在位年数均待定。

> 残历不是“旧历的延续”，而是旧王离开后，旧地继续使用的一套纪年。新国官方用新历，旧民和地下遗迹仍用残历，形成双历并行。

## 五、历史时间线

| 纪年 | 事件 | 说明 |
| --- | --- | --- |
| 旧历末叶 | 古国衰落 | 灾害、死伤、迁徙；中央对边地失控 |
| 旧历末年 / 残历元年 | 旧王离开 | 旧国不再有王；留下不愿走的人、流民、异邦人 |
| 残历 1–T 年 | 过渡政权 | 散人政府接手；异邦人投靠；佣兵自重；异邦入侵 |
| 残历 1–T 年 | 民间武装土匪化 | 以“非友即敌”清洗、奴役不追随者 |
| 残历 T+1 年 / 新历元年 | 新国建立 | 军阀与散人集团取代过渡政权 |
| 新历 1–4 代 | 新国扩张（暂定） | 以“自古以来的领土”对外征讨；具体分界待定 |
| 新历 5–10 代 | 守成与内耗（暂定） | 旧民怀念旧王；官修史书称旧王暴君 |
| 新历 11 代 | 新国亡国 | 第十一代王无作为；旧地再次失序 |
| 游戏当前时间 | 待定 | 建议放在新历第十一代前后，但暂不写死 |

## 六、与现有设定的衔接

- 地心炉、三灾、四守护单元的设定继续有效；古国衰落与旧王离开是这套设定的历史背景。
- 旧王在停炉后离开；停炉没有真正熄灭炉心，炉心仍悬浮于熔岩之上。四守护单元仍在旧王都地下执行旧命令。
- 旧王无嗣；主角是人造人，与旧王本质同源，不是旧王的后代。核心识别的是同源签名，不是世俗血缘。
- 新国不知道地心炉的存在，把三灾解释成天灾或旧王朝的罪证；官方史书把旧王写成暴君。
- 主角在核心门前用旧王朝的同源签名获得权限；旧国“推举而治”的传统与同源权限可以并存：推举决定谁治理，同源签名决定谁有权进入核心。
- 新国的“自古以来”是政治宣传，不等于旧国真的有过中央集权的帝国版图。
- 炉心、矿石、人造人和矿石病的详细设定见 [`核心、矿石与人造人.md`](核心、矿石与人造人.md)。
