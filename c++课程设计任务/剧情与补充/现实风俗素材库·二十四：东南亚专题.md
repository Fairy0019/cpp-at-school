# 现实风俗素材库·二十四：东南亚专题

> 状态：素材收集 v0.1，2026-11-26。
>
> 用途：按地区深挖东南亚风俗，每条给“具体地区/民族 + 做法 + 逻辑 + 可借 + 出处”。
>
> 说明：
> - 东南亚不是一个“文化”；印尼、泰国、菲律宾、缅甸、柬埔寨/老挝、马来西亚/新加坡差异极大。
> - 出处以民族志/历史研究/博物馆/UNESCO 为主；百科只当入口。
> - `【高】` = 学术/博物馆/UNESCO 来源较可靠；`【中】` = 来源较泛/地区差异大，写进游戏前再核；`【待核】` = 只当线索。
> - 涉及殖民/宗教/政治的内容，写作时不要猎奇；借制度逻辑，不借“异域奇观”。

## 一、印度尼西亚

### 1. 互助 / gotong royong（印尼）【高】

- **做法**：社区/村庄共同劳动/修路/建房/葬礼/节日；有钱出钱/有力出力；互助是“社会义务/保险”。
- **逻辑**：没有国家福利，就靠“互相帮忙”；谁不帮，谁被排斥。
- **可借**：坑沿镇的“灰互助/炉帮”；玩家可以帮/被拒/被利用；互助是“社区/义务/生存”。
- **出处**：Gotong royong 研究（具体版本待核）。

- **逻辑**：kampung 是“熟人社会/家”；谁住/谁走，代表身份/关系。
- **可借**：坑沿镇的“灰甘榜/炉巷”；玩家可以住/被监视/被帮；kampung 是“邻里/贫困/家”。

## 七、怎么用

1. **先看具体地区/民族**：不要写“东南亚人相信……”，写“印尼爪哇/泰国/菲律宾/缅甸/柬埔寨/马来西亚……”。
2. **再看“谁在讲/谁受益”**：殖民/宗教/国家/旅游/资本都在改写这些风俗。
3. **借逻辑，不借表面**：互助→灰帮；kampung→灰巷；slametan→灰宴；spirit house→灰龛；longyi→灰衣。
4. **标注可信度**：`【中】/【待核】` 的条目，写进游戏前再查。
5. **不要猎奇**：殖民/屠杀/宗教/贫困，背后是真实的人；写制度，不写“异域奇观”。
