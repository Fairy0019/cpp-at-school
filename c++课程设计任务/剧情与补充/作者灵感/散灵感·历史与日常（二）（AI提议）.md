## 一、集体负责

### 1. Murdrum fine（中世纪英格兰）

如果一个人在某个百户区被杀、凶手没抓到，整个社区要交一笔罚款。不是“谁杀的谁负责”，是“你们没交出凶手，你们一起赔”。
→ 坑沿镇可以有一条“灰法”：矿里死了人、找不到凶手，全镇/全矿一起罚；于是大家会互相包庇，也会互相出卖。

### 2. Hue and cry（中世纪英格兰）

有人犯罪，受害者/目击者要大声呼喊，所有听到的人都必须放下手里的活去追；不去，整个社区被罚。
→ 坑沿镇的“灰喊”：一喊抓贼，所有人都要追；不追的人被标记；喊声可以被伪造/利用。

### 3. Tithing / frankpledge（中世纪英格兰）

十户人家编成一组，互相担保；一个人犯法，其他九户要负责把他交出来。你没有“个人隐私”，你是“十人组”的一部分。
→ 坑沿镇的“灰十户”：十户一牌，一户出事十户连坐；玩家可以拆组/换组/被组出卖。

## 二、国家拿走你的身体/孩子

### 4. Press gang（英国，18–19 世纪）

海军在港口/酒馆/街上强行抓人当水手；被抓的人可能几年回不来。合法绑架。
→ 新国的“灰捕/炉征”：军队在城门/酒馆抓壮丁；身份牌被收走；家人不知道他去了哪。

### 5. Devshirme（奥斯曼帝国）

从基督教家庭征走男孩，改宗/训练/进入禁卫军/官僚；有的做到高官，但永远离开原生家庭。
→ 新国的“灰征童”：边境/矿区征走孩子，训练成官员/士兵/监军；多年后他回来，家人不认识他，他也不知道自己是谁。
（写作时不要把被征儿童当奇观；重点在家庭/身份/权力。）

## 三、城市的“脏活经济”

### 6. Pure finder（英国，18–19 世纪）

收集狗粪卖给制革/制硝的作坊；臭、脏、被看不起，但有人靠这个活。
→ 坑沿镇的“灰拾”：专门收集某种脏东西（矿渣/尸灰/狗粪/尿）卖给人；他们知道城里所有暗道。

### 7. Tosher（伦敦，19 世纪）

在下水道里捡钱/金属/骨头/死人东西；涨潮/放水时可能被冲走。
→ 王都的“灰掏”：在下水道/旧管道里捡东西；他们最先发现尸体/旧王遗物/秘密通道。

### 8. Knacker（欧洲）

处理老/死马，做肉/骨/皮/胶/肥皂；穷人吃马肉，富人嫌脏。
→ 坑沿镇的“灰剥”：处理死兽/死怪；他们知道哪种肉能吃、哪种骨头能做工具；也是消息灵通的人。

## 四、国家在数你/标记你

### 9. Swan upping（英国）

每年在河上数天鹅、给天鹅做记号，标记归属（王室/教会/行会）。国家连鸟都要数。
→ 王都的“灰鹅/灰鸟记”：每年数一种鸟/兽，给它们做记号；谁拥有哪只鸟，代表权力；一个孩子被像天鹅一样做记号。

### 10. Fire mark（英国，18–19 世纪）

火灾保险公司在房子上钉一块金属牌；只有买了保险的房子，消防队才救。没牌的房子烧了白烧。
→ 坑沿镇的“灰火牌”：只有挂了牌的房子，火队才救；穷人没牌，房子烧了没人管；“火认识谁付过钱”。

### 11. Ale taster（英格兰）

官方“尝酒人”检查麦酒的质量/价格；他可以说这桶酒不合格，也可以收贿赂。
→ 坑沿镇的“灰尝”：官方尝酒/尝药/尝矿料的人；他可以放行/没收/下毒；玩家可以收买/毒他/替他。

## 五、民间：房子、树、死人

### 12. Corn dolly（欧洲）

收割最后一捆麦子，编成娃娃/形状，代表“谷物精灵”；保存到明年，再埋回田里。
→ 坑沿镇的“灰穗人”：最后一捆矿料/麦子做成小人；保存/丢失/烧掉会影响来年；玩家可以偷/还/毁。

### 13. Apple wassail（英国）

冬天到果园，围着苹果树唱歌/敲锅/倒酒，叫醒树神，求来年丰收。
→ 坑沿镇的“灰树醒”：到灰林/矿脉边唱歌/敲锅/倒酒，叫醒“树/矿”；不唱，来年塌方/歉收。

### 14. Witch bottle / shoe in the wall（英国/欧洲）

把瓶子/旧鞋藏在墙里/烟囱里/门槛下，挡巫术/恶灵；装修时才发现。
→ 坑沿镇的“灰藏”：墙里藏着瓶子/鞋/骨头/纸条；每一件是一个故事；玩家可以拆/藏/被诅咒。

### 15. Leper window / leper bell（中世纪欧洲）

麻风病人不能进教堂，只能从墙上的小窗看弥撒；他们走路要摇铃，提醒别人避开。
→ 王都的“灰窗/灰铃”：矿石病人/死灵不能进镇，只能从窗/门缝看；他们摇铃，别人就知道要躲；“看得见，进不来”。

### 16. Doom painting（中世纪教堂）

教堂墙上画“最后审判”：天堂/地狱/称灵魂/恶魔；不识字的人看画就懂。
→ 王都的“灰审判墙”：一面墙画着核心/四骑士/地狱；玩家可以读/改/被画进去；墙会“审判”人。

## 六、完全原创

### 17. 死者债 / debt of the dead

人死后，葬礼上要大声念出他欠的债；继承人可以“接债”或“拒债”。拒债的话，死者会变成“债鬼”，跟着债主。
→ 旧王的债/新国的债/主角继承的债；玩家可以接/拒/转嫁；债鬼可以是一个角色。

### 18. 面具登记 / mask registry

每人必须在议会/城门登记自己的面具；没登记的面具叫“白面”，可以被任何人杀死而不算谋杀。
→ 王都的“灰面册”；玩家可以登记/伪造/戴白面；白面是无名者/死人的脸。

### 19. 记忆税 / memory tax

国家按“记忆”征税：穷人可以把痛苦的记忆卖给“记忆商”抵税；被卖掉的记忆会进黑市/药/酒。
→ 坑沿镇的“灰忆”；玩家可以卖/买/找回记忆；主角的记忆可能是买来的/被卖掉的。

### 20. 名字拍卖 / name auction

人死后没有继承人，他的名字会被拍卖；买主可以继承死者的名誉/债务/祭祀；名字变成一种资产。
→ 王都的“灰名拍”；玩家可以买/卖/伪造名字；一个穷人买了一个贵族名字，被人追杀。

### 21. 房屋宣誓 / house oath

房子在法律上是“人”：可以欠税/被起诉/继承；房主死了，房子要重新宣誓；空房子会变成“野屋”，谁都能占。
→ 坑沿镇的“灰屋誓”；玩家可以占/修/被屋赶；房子有自己的“名字/脾气”。

### 22. 门税 / door tax

按门的数量征税；穷人家只留一个门，几家人共用一个门；门是奢侈品。
→ 坑沿镇的“灰门税”；玩家可以数门/封门/偷门；门是阶级/隐私/逃生路线。

### 23. 名字钟 / name clock

一口钟/一座钟，不显示时间，只显示死者的名字；每个小时是一个名字；全镇按死者的名字安排作息。
→ 王都的“灰名钟”；玩家可以查/改/停；时间不是数字，是名字。

### 24. 空椅 / empty chair

每家有一把空椅，给死者/缺席的人；吃饭要摆上；忘了摆，死人会来坐。
→ 坑沿镇的“灰椅”；玩家可以坐/收/被占；空椅是“家里的第四个人”。
