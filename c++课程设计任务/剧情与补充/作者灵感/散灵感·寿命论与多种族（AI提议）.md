## 一、寿命论：不要只写“长生种爱上短生种”

### 1. 蜉蝣之交 / mayfly friendship

长生种不愿和短生种做朋友：对长生种来说，二十年只是一个季节；对短生种来说，那是一辈子。短生种会怨恨自己只是对方“生命里的一个阶段”；长生种则厌倦了参加葬礼。
→ 一个长生种角色的房间里挂着几十幅小肖像，每一幅是一个死去的短生朋友；主角是几百年来第一个新肖像。

### 2. 谁记得 / 记忆所有权

长生种亲眼见过旧王国；短生种只能靠档案/口述/仪式。谁有资格说“历史是这样的”？是活了几百年的人，还是写了几百年档案的人？
→ 一个短生种档案官和一个长生种见证人争夺同一段历史；玩家可以选信谁。

### 3. 日落法 / sunset law

长生种几百年积累房产/土地/职位；短生种多数却等不到他们死。于是法律规定：长生种每 X 年必须转让/出售一部分资产，或缴纳“世纪税”。
→ 长生种说这是抢劫，短生种说这是正义；玩家可以看见两边都有道理。

### 4. 多数与长寿 / demographic imbalance

短生种是人口多数，但长生种占着议会/法院/银行；或者反过来，长生种是少数，被短生种多数恐惧/排斥。选举年龄/投票权重/“代际 senate”成为冲突。
→ 一个短生种政客说：“你们不是不老，你们只是死得慢；我们不是短命，我们只是等不起。”

### 5. 你效忠过几个国家 / time-based citizenship

一个长生种一生经历三个国家；每个国家都要求他宣誓效忠。国家死了，他还活着；他的忠诚被当成可疑。
→ “无长寿籍者”：护照/身份牌比本人先过期；一个长生种成了“没有国家的人”。

### 6. 悲伤经济 / grief economy

长生种雇佣短生种做“终身伴侣/送葬人/记忆保管人”；短生种知道自己的结局，签合同、拿钱、被记住。
→ 一个职业叫“最后的朋友”：陪长生种走完一段，然后被写进对方的“朋友博物馆”。

### 7. 成年年龄的冲突 / age of majority

一个 200 岁的精灵在族里还是孩子；一个 20 岁的人类已经成年。恋爱/婚姻/ consent/继承/参军，法律按哪个算？
→ 一桩跨种族婚姻/案件；一方说“她还是孩子”，另一方说“她已经成年”；玩家可以看见“年龄”也是文化/权力。

### 8. 短生兵/长生官 / expendable soldiers

军队喜欢短生种士兵：反正他们很快会死；长生种做军官/决策者。短生种士兵说：“你们用我们的命买时间。”
→ 一个长生种将军和一个短生种士兵的对话；将军说“我会记住你”，士兵说“你连我名字都记不住”。

## 二、其他方向

### 9. 骨誓 / bone oath

在祖先的骨头上发誓；违约，骨头被磨成粉，名字被除去。誓约不是纸，是骨头。
→ 一个政治协议/婚约/停战，签在骨头上；谁违约，谁的祖先被“再杀一次”。

### 10. 债面 / debt mask

欠债的人戴一张面具，上面写着欠多少；还清才能摘。面具越重，债越多；有人一辈子摘不下来。
→ 坑沿镇的“债面”；玩家可以替人还/抢/伪造；面具是经济/身份/羞辱。

### 11. 天气市场 / weather market

农民/商人买卖“未来的雨”；干旱时雨价飞涨；穷人买不起雨，富人囤雨；一个“雨泡沫”。
→ 坑沿镇的“灰雨/炉水”；玩家可以囤/卖/偷；天气是商品，也是权力。

### 12. 名字瘟疫 / name plague

一种病让人忘记自己的名字；国家发“临时名”；黑市卖“好名字”；主角免疫/或第一个感染。
→ 王都的“灰名疫”；玩家可以给自己/别人取名；名字是药，也是武器。

### 13. 记忆继承 / memory inheritance

人死后，记忆可以传给继承者/陌生人；继承者同时继承死者的债/爱/仇；一个“记忆市场”。
→ 主角可能继承了旧王的记忆/第一个造物的记忆；玩家要分辨“这是我的记忆，还是别人的”。

### 14. 最后之城 / last city

一座城相信自己是“最后的人类聚落”；一个斥候发现另一座城；城的宗教/身份/配给体系崩溃。
→ 坑沿镇可能只是“之一”，不是“最后”；玩家可以带消息/隐瞒/利用。

### 15. 历法战争 / calendar war

两个国家用不同历法；一份条约的日期在两边不是同一天；一场战争因为“你迟到了一天”爆发。
→ 王都的“三套历法”；玩家可以挑日子/改历/被历法害。

### 16. 静钟 / silent bell

一口钟不发出声音，但会“杀死”一个特定的人；国家用它做“无声处决”；死者不知道自己为什么死。
→ 王都的“灰钟”；玩家可以查/偷/停；死亡没有声音，只有名单。

### 17. 债务禧年 / debt jubilee

每 50 年，所有债务清零；富人恐惧，穷人等待；一个“禧年教派”倒计时；有人提前转移资产/伪造债务。
→ 坑沿镇的“灰禧”；玩家可以等/破坏/利用；债务是周期，也是政治。
