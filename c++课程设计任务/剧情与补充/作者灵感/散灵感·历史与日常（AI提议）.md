## 国家伸手进你家

### 1. 硝石人 / saltpeter man（近代早期英格兰/欧洲）

国家授权“硝石人”进民宅、谷仓、马厩，挖开地面取硝石（做火药）。他们有权进你家，挖个洞，再走。老百姓恨他们，但法律允许。
→ 新国的“硝石官/矿料官”可以进任何人家，挖开地板找“炉料”；地上留下一个洞，像国家在你家开了一口井。

### 2. 窗税/壁炉税（英格兰，17–19 世纪）

按窗户数量/壁炉数量征税。穷人把窗户砌死，房子留下“盲眼”；富人装玻璃、烧壁炉。
→ 坑沿镇的房子有的窗户被砖封死，有的亮着灯；“房子的眼睛”就是阶级。税吏数窗户/数火，像数人头。

### 3. 宿营 / billet（近代欧洲）

士兵被强制安排住进民宅，家庭必须提供房间/食物/燃料。士兵是陌生人，家庭没有拒绝权。
→ 新国军队进镇，每家必须腾一间房；士兵睡在女儿的床上，父亲睡厨房；“国家睡在你家”。

### 4. 征发 / purveyance（英格兰，中世纪–1660）

国王有权按低于市场的价格征用食物/马/车/燃料；农民/商人必须卖，不能拒绝。
→ 新国/军阀“征发”矿料/粮食/驴马；给一张盖印的收据，钱很少/没有；收据后来变成废纸。

## 名字、身份与法律

### 5. 定居证 / settlement certificate（英格兰，1662–）

穷人属于某个教区；离开教区要带“定居证”，否则被当作流浪者遣返。你没有“移动权”，你属于一个地方。
→ 坑沿镇的人有“教区/矿籍/牌籍”；没有证的人不能进城/住店/结婚；城门机器问“你属于哪里”，不是“你是谁”。

### 6. 贫困徽章 / badge of poverty（英格兰，17–19 世纪）

领取救济的穷人必须在衣服上缝一个徽章（通常字母“P”），公开标记“我是靠救济的人”。
→ 坑沿镇的“灰徽/炉徽”；领救济的人必须戴；徽章是通行证，也是羞辱；有人偷/伪造/烧掉它。

### 7. 死者物 / deodand（英格兰，中世纪–1846）

一件物品/动物导致人死亡，它会被“没收给国王/上帝”，有时公开拍卖/献给教堂。不是人受审，是“东西”有罪。
→ 一把刀/一辆车/一块石头“杀了人”，被带到法庭/教堂/拍卖；物品有名字/编号；主角可以买下/偷走/毁掉它。

## 死亡、房子与沉默

### 8. 透明墓 / transi tomb（晚期中世纪欧洲）

墓碑上刻两具身体：一具穿着衣服/体面，一具是腐烂/虫蛀的尸体。铭文大意：“你现在看我，将来也会这样。”
→ 旧王的墓/碑同时刻“王”和“腐尸”；玩家先看到王，再看到虫；新国的纪念碑只刻“英雄”，不刻尸体。

### 9. 丧徽 / hatchment（英格兰/欧洲）

人死后，家里挂一块菱形木板，画死者的纹章/名字；挂一段时间，再移走。房子“穿着死者的名字”。
→ 坑沿镇的房子门口挂“丧徽”；挂得越久，代表越有钱/越有地位；穷人只用一块黑布。

### 10. 骂妇嘴套 / scold’s bridle（英格兰/欧洲）

一个铁笼/面具，套在“爱骂人/爱说话”的女性头上，嘴里有铁片，让她不能说话；有时被牵着游街。
→ 王都的“静默面具”；犯“多嘴/造谣/抗命”的人被戴上；面具里有舌片/刺；这直接接你的面具文化，但更残酷。

### 11. 酒鬼桶 / drunkard’s cloak（英格兰，17–18 世纪）

把醉汉/犯人装进一个只有头和手能伸出的木桶，让他自己走/被推着游街。公开羞辱，像“移动监狱”。
→ 坑沿镇的“灰桶刑”；犯法的人被装进桶里，只能露出头和手；桶上写罪名；他走到哪，笑声跟到哪。

## 隐藏的守护者与民间

### 12. 教堂黑狗 / church grim（英格兰/北欧民间）

新墓地第一个下葬的人/动物，灵魂要留下来看守墓地；常被想象成一条黑狗。谁先葬，谁当“守墓者”。
→ 王都的墓地/万人坑有一只“灰狗”；第一个被埋的人变成它；玩家可以问它/喂它/替它。

### 13. 墙中隐修者 / anchorite（中世纪欧洲）

一个人自愿（或被安排）被砌进教堂墙里的小房间，终生不出；人们从一个小窗给她送饭/问事。她“活着，但已经死了”。
→ 王都的墙里有一个“灰隐者”；玩家隔着墙跟她说话；她知道旧王/新国的事，但永远出不来。

### 14. 告诉蜜蜂 / telling the bees（欧洲民间）

家里有人死/结婚/搬家，必须告诉蜜蜂；否则蜜蜂会离开/死。动物/物件也要“知道”。
→ 坑沿镇的人死后，家人去告诉蜂箱/炉子/井/矿灯；“不告诉蜜蜂”会招灾；玩家可以替人告诉/忘记/利用。

### 15. 河泥拾荒者 / mudlark（伦敦，18–19 世纪）

穷人在退潮的河滩上捡东西：木头/铁/硬币/骨头/尸体。河是“免费的垃圾场/坟墓”。
→ 坑沿镇的“灰滩拾荒者”；退潮/灰落后，他们去捡；他们最先发现尸体/旧物/沉船。

### 16. 盗尸者 / resurrectionists（英国，18–19 世纪）

医学院需要尸体，盗尸者挖新坟/贿赂守墓人；穷人卖亲人的尸体；守墓人/铁笼/防盗墓。
→ 王都的“灰解院”需要尸体；盗尸者/守墓人/家属形成黑市；玩家可以守墓/卖尸/查案。

## 完全原创

### 17. 影子税 / shadow tax

城市按建筑物投下的阴影面积征税；穷人把房子建得低/窄/背光，富人建高塔；太阳成了税吏。
→ 坑沿镇的“灰影税”；房子越矮越便宜，街道永远在阴影里；玩家可以通过阴影找路/藏人/逃税。

### 18. 名字典当 / name pawn

穷人可以把“名字”押给当铺换钱；还不上，名字归当铺，本人变成“无名者”，不能结婚/继承/立碑。
→ 王都的“灰当/炉名”；主角可以典当/赎回/伪造名字；无名者组成地下社区。

### 19. 无名者之钟 / bell of the unnamed

一口钟，只在有人“没有名字地死”时响；钟响后，全镇必须在钟停之前给死者找到一个名字，否则死者会留下来。
→ 坑沿镇的“灰钟”；玩家可以给无名死者取名/查名/拒绝；钟声是倒计时。

### 20. 尸路 / corpse road

一条只给死者走的路；活人走它，必须替死者带路/抬棺/讲一个死者的故事，否则会被“留下”。
→ 王都的“灰路”；玩家可以走/绕/被拦；路上有棺材/名字/故事。
