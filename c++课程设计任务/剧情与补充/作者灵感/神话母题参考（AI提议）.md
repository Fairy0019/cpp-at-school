# 神话母题参考（AI 提议）

> 状态：AI 提议，不是作者原意，不是 canon；不做成卡，可删可改。
>
> 下面借的是**结构/母题**，不是把真实神祇直接搬进游戏；游戏最好有自己的神话，只是“听起来像”这些。

## 一、创造与造物

### 1. 普罗米修斯（希腊）

泰坦偷火给人类，被绑在山上，鹰每天吃他的肝；他是“给人类带来火/技术，却被自己帮助的对象/神惩罚”的造物者。
→ 旧王把炉心/火给共同体，自己却被“责任/愧疚”啄食；炉心是“偷来的火”，旧王是“被罚的普罗米修斯”。

### 2. 皮格马利翁（希腊/奥维德）

雕塑家爱上自己的雕像，神让雕像活过来；创造者爱的是“自己理想中的造物”，不是造物本身。
→ 旧王造主角，可能爱的是“能替他回去的自己”，不是主角；主角发现自己是“被爱的理想/被爱的替身”。

### 3. 魔像（犹太民间）

用泥土造人，把神圣名字/纸条放进它嘴里，它就动；擦掉名字/取出纸条，它就死。造物靠“名字”活着。
→ 主角是“有名字的魔像”；核心/旧王用签名唤醒他；擦掉名字=失去自己。可以更明确地借“名字在嘴里/额头/纸上”的意象。

### 4. 波波尔·乌（玛雅）

神用泥、木、玉米造人；泥人/木人失败，被洪水毁掉；最后用玉米造出真正的人。创造是“试错/失败/毁掉重来”。
→ 第一个造物（绞索房间）是“失败的泥人/木人”；主角是“玉米人/最后一个版本”；旧王可能造过很多次。

### 5. 伊米尔/提亚玛特（北欧/美索不达米亚）

原初巨人/混沌巨兽被杀，身体变成世界：骨头=山，血=海，头骨=天。世界是“一具尸体”。
→ 王都/炉心是“建在一具尸体上”；旧王/古神的身体变成城市/矿脉；玩家在地下走的是“巨人的内脏”。

## 二、洪水、末日与新时代

### 6. 诺亚/吉尔伽美什洪水（近东）

神发洪水毁灭人类，选一个人/一家人造船/保存种子/动物；洪水后是新 covenant/新世界。幸存者是“被选中的人”，也是“幸存者内疚”的人。
→ 三灾/大沉没可以是一次“洪水”；旧王/新国/坑沿镇都有人“被选中/被留下”；船/方舟可以是地下城/高塔。

### 7. 诸神黄昏/芬布尔之冬（北欧）

先是三个没有夏天的冬天（Fimbulwinter），然后诸神/怪物互相杀死，世界烧毁/沉没；之后大地从水中重生，少数幸存者重新开始。
→ 四骑士/三灾/新国灭亡可以借“先是长冬，再是终战，再是重生”；结局不是“世界结束”，是“少数人从水里/灰里爬出来”。

### 8. 迦利时代/卡尔基（印度）

历史分成四个时代，最后是“黑暗/堕落”的迦利时代；毗湿奴的最后化身卡尔基骑白马、持剑，结束旧时代、开启新时代。
→ 新国晚期=迦利时代；有人相信“炉心/骑士/主角”是卡尔基；但“救世主”可能只是另一个毁灭者。

### 9. 大洪水后的“石头人”（希腊丢卡利翁/皮拉）

洪水后，幸存者把石头扔到身后，石头变成新的人类。新人来自“石头/死者的骨头”。
→ 坑沿镇的人自称“石头里出来的/灰里出来的”；他们的祖先是“被扔在身后的石头”；主角可能是“最像人的那块石头”。

## 三、冥界、死亡与记忆

### 10. 奥菲斯与欧律狄刻（希腊）

歌手下冥界救妻子，条件是不能回头看她；他回头，她消失。爱/怀疑/失去。
→ 主角下核心/地下城“救”某个人（旧王/第一个造物/自己）；“不要回头”可以是一个机制/禁令；回头=看见真相/失去。

### 11. 伊南娜下冥界（美索不达米亚）

女神每过一道门，就被要求脱下一件首饰/衣服/权力象征；她赤身见到冥后，被杀，后被复活。下冥界=一层层剥掉身份。
→ 主角下王都，每过一层就失去一件“身份”（身份牌/面具/名字/武器/记忆）；到核心时，他“什么都没有”，只剩自己。

### 12. 奥西里斯（埃及）

被兄弟杀死/分尸/散落各地；妻子伊西斯找回/拼合/复活；他成为冥界之王，儿子荷鲁斯复仇/继位。
→ 旧王被“分尸”成四骑士/四份证词/四件遗物；主角/回声/骑士拼合他；但拼回来的不是原来的他，是“冥界之王/回声”。

### 13. 孟婆汤（中国）

死者过奈何桥，喝孟婆汤，忘记前世，才能投胎。忘记是“慈悲/惩罚”。
→ 王都的“灰汤/炉汤”：喝下忘记旧王/自己；主角可以选择喝/不喝/偷换；记忆税/记忆买卖可以接这条。

## 四、王权、牺牲与替身

### 14. 渔王（亚瑟王传说）

国王受伤/残废，土地也跟着荒芜；只有“纯洁的骑士”问出正确的问题，才能治愈国王/土地。
→ 旧王受伤/离开，王都/炉心跟着荒芜；主角要问“正确的问题”（你恨我吗/你是谁/我是什么）；问错/不问=土地继续荒。

### 15. 国王的两个身体（中世纪政治神学）

国王有“自然身体”（会死/病/老）和“政治身体”（永不死的王权）；国王死了，王权立刻传给下一个。
→ 旧王的肉体死了，但“签名/回声/王位”还在；新国的“第一公民”也有两个身体（人/国家）；主角面对的是“没有身体的政治身体”。

### 16. 年王/替罪王（古代近东/欧洲民间）

每年选一个“王”/替罪者，享乐一段时间，然后被牺牲/驱逐，替共同体带走罪/灾。
→ 旧国的“王”是年度尊称，但“年王”的黑暗版本是：每年选一个人当“王”，然后让他承担炉心的危险/罪；旧王可能就是“被选中的年王”。

### 17. 伊菲革涅亚/耶弗他的女儿（希腊/圣经）

父亲许愿/被要求献祭女儿，女儿被牺牲/替换成鹿；vow/战争/无辜者。
→ 旧王/新国为了“大局”牺牲一个孩子/造物/替身；主角是“被献祭/被替换的伊菲革涅亚”；“鹿”可以是替身/替死鬼。

## 五、命运、欺骗与面具

### 18. 卡珊德拉（希腊）

她能预言真相，但被诅咒“没人相信她”；她说得越对，越被当成疯子。
→ 坑沿镇有一个“灰卡珊德拉”：她/他知道炉心/新国要出事，但没人信；玩家可以信/不信/利用；她说对了也没有好下场。

### 19. 洛基（北欧）

诡计之神/变形者/边界破坏者；他既帮神又害神，最后导致诸神黄昏；被绑/受罚。
→ 一个“灰洛基”角色：他/她破坏规则/身份/仪式，可能是骗子/救星/灾难；玩家可以合作/出卖/被他出卖。

### 20. 命运三女神/诺恩（希腊/北欧）

三个女人纺线/量线/剪线，决定每个人的寿命；她们不是“神”，是“必然”。
→ 王都的“灰三女”：纺身份牌/面具/名字的线；剪线=死亡；玩家可以偷线/换线/求她们。

### 21. 狄俄尼索斯/酒神（希腊）

面具/酒/狂喜/theater/撕裂/重生；他让国王/城邦失去理智，也被城邦崇拜。
→ 王都的“灰酒神/炉狂欢”：面具节/酒/舞蹈/附身；玩家可以在狂欢中看见/失去自己；酒神是“面具与失控”的神。

### 22. 美杜莎/戈耳工（希腊）

看她的人会变成石头；她的头被砍下后仍有力量；脸=武器/恐惧/保护。
→ 王都的“灰面/炉面”：一张不能看的脸/面具；看它=石化/失忆/被控制；面具可以当武器/护身符。

### 23. 塔罗斯（希腊）

青铜巨人/自动机，守护克里特；唯一的血管/钉子/弱点；投石/火/拥抱。
→ 四骑士/核心守卫是“塔罗斯式”的自动机；它们有一个“唯一的弱点/名字/钉子”；玩家可以找/拔/利用。
