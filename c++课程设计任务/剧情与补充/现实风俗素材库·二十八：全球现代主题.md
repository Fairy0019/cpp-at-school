# 现实风俗素材库·二十八：全球现代主题

> 状态：素材收集 v0.1，2026-11-26。
>
> 用途：收 20–21 世纪的全球现代文化/制度，每条给“具体地区/案例 + 做法 + 逻辑 + 可借 + 出处”。
>
> 说明：
> - 这一卷偏“现代生活/全球化”，不是传统民俗；但同样是“人怎么过日子”的素材。
> - 出处以历史研究/UNESCO/博物馆为主；百科只当入口。
> - `【高】` = 学术/UNESCO 来源较可靠；`【中】` = 来源较泛/地区差异大，写进游戏前再核；`【待核】` = 只当线索。
> - 涉及殖民/资本/劳动/战争的内容，写作时不要猎奇；借制度逻辑，不借“奇观”。

## 七、怎么用

1. **先看具体地区/案例**：不要写“现代人……”，写“美国/韩国/全球/20 世纪……”。
2. **再看“谁在讲/谁受益”**：资本/国家/平台/劳动者/消费者都在争解释权。
3. **借逻辑，不借表面**：足球→灰赛；社交媒体→炉网；集装箱→炉箱；抗生素→炉药；快餐→炉食。
4. **标注可信度**：`【中】/【待核】` 的条目，写进游戏前再查。
5. **不要猎奇**：殖民/劳动/成瘾/贫困，背后是真实的人；写制度，不写“奇观”。
