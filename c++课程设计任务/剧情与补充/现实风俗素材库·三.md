# 现实风俗素材库·三：深挖卷

> 状态：素材收集 v0.1，2026-11-26。
>
> 用途：在前两卷的基础上，按“法律/刑罚、货币/市场、食物/禁忌、身体/服饰、动物/自然、儿童游戏/教育、疾病/医疗、战争/俘虏”八个方向深挖。
>
> 标记：`【高】` = 常见历史/民族志记载，较可靠；`【中】` = 地区性较强或细节有差异，写进游戏前再核；`【待核】` = 把握不大，只当线索。
>
> 注意：本卷涉及刑罚、战争、疾病、身体改造，写作时不要把暴力/痛苦当奇观；借“制度逻辑”，不要借“血腥表面”。

## 一、法律与刑罚

### 1. 冷水神判（中世纪欧洲等）【高】

- **做法**：把被告绑起来投入冷水/河/池。若下沉，视为“水接受无辜者”，无罪；若浮起，视为“水拒绝罪人”，有罪。有时会在身上绑绳子控制沉浮。
- **逻辑**：水是纯洁的裁判；身体反应就是判决。人不是裁判，神/自然才是。
- **可借**：核心/炉心的“验证”可以是一场冷水/熔岩神判：沉下去的人无罪，浮上来的人有罪。玩家要选择信不信这套。

### 2. 热铁/火神判（中世纪欧洲、南亚等）【高】

- **做法**：被告手持烧红的铁/走过火堆/把手伸进沸水；伤口在若干天内愈合=无罪，化脓=有罪。
- **逻辑**：神会保护无辜者的身体；伤口是判决书。
- **可借**：四骑士/核心用“手伸进炉火”验证签名；主角的手能不能愈合，决定他是不是“维护者”。

### 3. 毒神判（马达加斯加、西非等）【中】

- **做法**：让被告吞下有毒的植物/药剂（如 tangena、sasswood）；呕吐/存活=无罪，死亡=有罪。有时全家/全村一起受审。
- **逻辑**：毒是神的判断；身体能不能承受，就是真相。
- **可借**：矿区用“矿石毒”审人；能吐出结晶的人无罪，吐不出的被当成“引炉者”。

### 4. 决斗裁判（中世纪欧洲）【高】

- **做法**：双方/代理人武装决斗，赢者被视为神判胜者；决斗可以解决谋杀、叛国、财产、荣誉纠纷。
- **逻辑**：神保佑正义者；武力是真相的证明。老弱可以请代理人。
- **可借**：封存骑士的“验证”是一场决斗；主角可以用战斗/代理人/拒绝战斗来回应。

### 5. 宣誓帮手 / compurgation（中世纪欧洲）【高】

- **做法**：被告找一群“宣誓帮手”（oath helpers）在法庭上发誓相信他无罪；他们不是证人，而是人品担保人。帮手越多/地位越高，越可能胜诉。
- **逻辑**：真相不如社区信任重要；有人替你担保，你就“清白”。
- **可借**：玩家要在镇子上找 N 个 NPC 为自己担保；担保人可能被收买/威胁/反悔。

### 6. 同态复仇 / lex talionis（古代近东、罗马等）【高】

- **做法**：以眼还眼、以牙还牙、以命抵命；伤害必须与受害者所受的相等。
- **逻辑**：复仇要有限度；不能多报，也不能少报。法律把私仇变成可计算的账。
- **可借**：王都的刑罚是“同态”的：弄瞎别人的人被弄瞎；伪造名字的人被除名。

### 7. 血钱 / wergild（日耳曼、伊斯兰、多地）【高】

- **做法**：杀人/伤害可以用钱赔偿给受害者家族；金额按死者的身份/性别/年龄计算。家属可以接受赔偿或拒绝。
- **逻辑**：人的命有价格；赔偿让两个家族重新可以共存。钱不是“买命”，是“止血”。
- **可借**：不同身份的人命价不同；主角的身份牌决定他死了能赔多少。

### 8. 放逐 / outlawry（古希腊、日耳曼、多地）【高】

- **做法**：把罪犯/政敌赶出城/共同体，剥夺名字/财产/保护；被放逐的人可以被任何人杀死而不算谋杀。
- **逻辑**：人之所以是人，是因为他在共同体里有位置；被赶出去，就变成“可杀的动物”。
- **可借**：王都的“出城”不是自由，是放逐；城门机器不让你再进来。

### 9. 民事死亡 / civil death（欧洲、殖民法等）【高】

- **做法**：罪犯/僧侣/修女被宣布“法律上死亡”：失去财产/婚姻/诉讼权，像一个死人。
- **逻辑**：法律可以杀死一个活人；身体还在，身份已经没了。
- **可借**：主角的临时身份牌被注销后，他变成“法律上的死人”；没人能看见他/和他交易。

### 10. 尸体审判 / Cadaver Synod（罗马，897 年）【高】

- **做法**：教皇斯蒂芬六世把前任教皇福尔摩苏斯的尸体挖出来，穿上教皇袍，放在法庭上审判；尸体被定罪、砍手指、扔进台伯河。
- **逻辑**：死亡不结束责任；尸体可以代表那个人受审。政治仇恨可以追到坟墓里。
- **可借**：旧王的尸体/遗物被新国审判；玩家可以替死人辩护/翻案。

### 11. 尸体出血 / bier right（欧洲民间、法律传说）【中】

- **做法**：把谋杀嫌疑犯带到尸体旁，或让尸体“看”嫌疑人；如果尸体流血/眼睛流血，就被认为指认了凶手。
- **逻辑**：死者自己会说话；身体是最后的证人。
- **可借**：绞索房间的尸体在主角靠近时流血/流泪；玩家要判断这是证据还是陷阱。

### 12. 孕妇暂缓 / pleading the belly（英国普通法）【高】

- **做法**：被判死刑的女囚如果怀孕，可以申请暂缓执行，直到孩子出生；有时会故意怀孕/伪造怀孕。
- **逻辑**：未出生的孩子是无辜的；母体暂时不能被杀死。身体状态改变法律。
- **可借**：女囚/女犯用怀孕/身体状态拖延刑罚；玩家可以帮她/揭穿她。

### 13. 国王触摸 / royal touch（中世纪欧洲）【高】

- **做法**：国王/女王触摸瘰疬病患者，被认为可以治病；仪式上有专门的祷告/硬币/触摸礼。
- **逻辑**：王的身体有神圣力量；权力不只是命令，也是治疗。
- **可借**：旧王的遗物/手套/面具可以“治病”；新国的第一公民模仿这个仪式。

### 14. 烙印/断肢（欧洲、中国、多地）【高】

- **做法**：罪犯被烙上记号/割耳/砍手/刺字，让所有人知道他的罪；记号终身不褪。
- **逻辑**：罪写在身体上；身体是公开的记录，不能伪造/洗掉。
- **可借**：王都的罪犯被烙上炉形记号；主角的身份牌可以伪造，但身上的烙印不能。

### 15. 债务监狱（欧洲、近代）【高】

- **做法**：欠债不还的人被关进监狱，直到家人/朋友替他还钱；监狱费用也要犯人自己付。
- **逻辑**：债务是人身控制；还不起钱，就失去自由。
- **可借**：坑沿镇的“深潜合同”违约者被关进矿坑；玩家可以替人还债/卖身。

### 16. 枷锁/公开羞辱（欧洲、中国等）【高】

- **做法**：罪犯被锁在广场/城门的枷锁/站笼里，任人围观/投掷；有时戴罪名牌/纸帽。
- **逻辑**：羞辱比疼痛更有效；公开示众让社区重新确认规则。
- **可借**：城门/市场的“示众柱”；玩家可以救人/扔石头/偷走罪名牌。

### 17. 识字免死 / benefit of clergy（英国）【高】

- **做法**：被判死刑的犯人如果能在法庭上读出一段拉丁文（通常是诗篇 51:1），就证明自己是“教士”，可以转交教会法庭，通常免死。
- **逻辑**：识字是身份/特权；会读一行字，就能从死里逃生。
- **可借**：王都的“读得出炉铭的人”可以免罪/进入核心；文盲只能等死。

### 18. 避难所 / sanctuary（中世纪欧洲）【高】

- **做法**：逃犯躲进教堂/修道院/特定区域，可以暂时不被逮捕；一定时间后必须离开/受审。
- **逻辑**：神圣空间可以暂停世俗法律；门/门槛是边界。
- **可借**：城门/炉心/墓地是避难所；玩家可以躲进去，但会失去时间/自由。

### 19. 动物审判（中世纪欧洲）【高】

- **做法**：动物（猪、狗、老鼠、蝗虫）被正式起诉、审判、判刑；有的被处死，有的被驱逐。
- **逻辑**：法律适用于一切有“行为”的东西；动物也是社区成员/污染源。
- **可借**：坑沿镇审判一只吃了尸体的狗；玩家可以替狗辩护，发现真正的凶手。

### 20. 替罪羊 / scapegoat（圣经、古希腊）【高】

- **做法**：把社区的罪/污染转移到一只动物/一个人身上，然后赶走/杀死；社区因此净化。
- **逻辑**：罪可以转移；需要一个“外面的人”承担。
- **可借**：四骑士/旧王被新国当成替罪羊；玩家可以揭穿/接受/利用这个叙事。

## 二、货币与市场

### 21. 铸币贬值 / debasement（罗马、中世纪、近代）【高】

- **做法**：国家在金币/银币里掺入 cheaper 金属，但面值不变；表面上钱没变，实际金属少了。
- **逻辑**：国家可以偷偷偷走人民的购买力；钱是国家的承诺，不是金属本身。
- **可借**：新国的“公民币”越铸越薄；老人按重量收钱，年轻人按面值收钱。

### 22. 铸币税 / seigniorage（多地）【高】

- **做法**：国家/领主垄断铸币，收“铸币费”；或者把新币按高于金属价值的面值发行，差额归自己。
- **逻辑**：谁有铸币权，谁就能收“隐形的税”；货币是权力的工具。
- **可借**：坑沿镇的“矿票”由商人发行；谁印票，谁抽成。

### 23. 汇票 / bill of exchange（中世纪/近代欧洲）【高】

- **做法**：商人在 A 地付钱，拿到一张纸，到 B 地兑钱；避免携带大量现金/跨境风险。
- **逻辑**：纸可以代替金属；信用/网络比钱本身重要。
- **可借**：王都的“信物/汇票”可以在不同营地/商店兑换；玩家可以伪造/抢劫/拒付。

### 24. 哈瓦拉 / hawala（南亚、中东等）【高】

- **做法**：通过一个信任网络，A 地的汇款人在网络里付钱，B 地的收款人凭暗号/信物取钱；没有正式银行/合同。
- **逻辑**：信任是货币；网络比机构更可靠。记录可以很少，甚至没有。
- **可借**：坑沿镇的商人用“暗号/半张牌”汇款；玩家要找到对得上的一半。

### 25. 抵押/按揭 / mortgage（多地）【高】

- **做法**：用土地/房子/物品做担保借钱；还不上，担保物归债主。
- **逻辑**：债务可以用“未来的家”做抵押；还不上，就失去家。
- **可借**：主角可以用身份牌/面具/武器做抵押；还不上，身份/脸就没了。

### 26. 海上保险 / marine insurance（近代欧洲）【高】

- **做法**：商人/船主为船/货物投保；船沉了/货丢了，保险公司赔。保费根据风险/航程计算。
- **逻辑**：未来可以被打赌/分摊；风险是一种可以买卖的东西。
- **可借**：坑沿镇的“深潜保险”：玩家付保费，死了/残了由商人赔给家属；商人会故意派你去危险的地方。

### 27. 期货 / futures（近代欧洲、日本等）【高】

- **做法**：现在就约定未来某时以某价买卖货物（米、郁金香、棉花）；价格波动决定盈亏。
- **逻辑**：未来的收成可以现在卖；投机者赌天气/战争/灾害。
- **可借**：商人提前买下“下一季的矿石/炉心热量”；如果炉心失控，期货暴涨。

### 28. 年金 / tontine（近代欧洲）【高】

- **做法**：一群人共同出一笔钱，每年领利息；成员死了，他的份额分给活着的人；最后活着的人拿走全部/大部分。
- **逻辑**：你的收益取决于别人死得比你早；长寿是投资。
- **可借**：坑沿镇的“深潜年金”：一群矿工共同出资，最后一个活着的人继承矿脉；有人开始“帮助”别人死。

### 29. 什一税 / tithe（中世纪欧洲等）【高】

- **做法**：农民把收成的十分之一交给教会/领主；可以用实物/钱支付。
- **逻辑**：生产本身要被抽成；神/领主对土地有优先权。
- **可借**：王都的“炉税”：每十块矿石抽一块给核心/守炉人；不交的人会被除名。

### 30. 关税/城门税 / customs（多地）【高】

- **做法**：货物进出城/港口要交税；税吏检查/估价/盖章；逃税是重罪。
- **逻辑**：城门是国家的手；谁控制门，谁就能抽成。
- **可借**：城门机器/税吏收“进城税”；玩家可以行贿/走私/伪造税印。

### 31. 走私 / smuggling（多地）【高】

- **做法**：绕过税关/禁令，偷偷运输货物/人；路线/暗号/贿赂是核心。
- **逻辑**：价格差/禁令创造黑市；走私者是“影子商人”。
- **可借**：坑沿镇有“暗门/旧管道”走私矿石/身份牌/人；玩家可以当走私者/卧底。

### 32. 假币 / counterfeiting（多地）【高】

- **做法**：伪造硬币/纸币/印版；用廉价金属/劣质纸；被发现是重罪（死刑/断手）。
- **逻辑**：货币是信任；假币破坏信任，所以刑罚极重。
- **可借**：假身份牌/假矿票/假路引；玩家可以识破/使用/被栽赃。

### 33. 赎金 / ransom（中世纪、海盗、战争）【高】

- **做法**：俘虏/人质被标价，家属/国家付钱赎回；付不起就被杀/卖为奴。
- **逻辑**：人的命有市场价格；战争也是一种生意。
- **可借**：玩家/NPC 被俘虏，需要凑赎金；商人可以借钱，但条件苛刻。

### 34. 黑市/配给（战时、计划经济等）【高】

- **做法**：官方配给/价格管制，黑市用高价/物物交换提供短缺商品；票证/关系/贿赂决定谁能买到。
- **逻辑**：管制创造短缺，短缺创造黑市；官方价格不是真实价格。
- **可借**：坑沿镇的“官方价/黑市价”双轨；玩家可以用票/关系/矿石碎片买不同的东西。

### 35. 面包暴动 / bread riot（近代欧洲等）【高】

- **做法**：粮价上涨/面包短缺时，人群冲击粮店/面包房/市政府，抢粮/砸机器；军队镇压。
- **逻辑**：面包是政治的底线；饿肚子的人不怕死。
- **可借**：坑沿镇缺粮，玩家可以煽动/平息/利用暴动。

### 36. 价格管制 / price control（多地）【高】

- **做法**：政府规定最高/最低价格；商人可能囤货/减量/黑市；违法者被罚。
- **逻辑**：价格是政治；管住价格，不一定管住供应。
- **可借**：营地/商店的物价由镇上的“规矩”决定；玩家可以影响规矩。

## 三、食物与禁忌

### 37. 孕妇饮食禁忌（多地）【高】

- **做法**：孕妇不能吃某些食物（兔肉、鱼、蛋、辛辣、冷食等），否则孩子会畸形/难产/被附身。
- **逻辑**：孕妇的身体是“开放”的，食物会影响胎儿；禁忌是保护/控制。
- **可借**：矿石病孕妇不能吃矿石盐/炉灰；违反的人生下“晶孩”。

### 38. 战士/猎人饮食禁忌（多地）【中】

- **做法**：出战/打猎前禁食某些动物/食物，或必须吃某些食物；违反会失去勇气/被猎物报复。
- **逻辑**：身体状态影响战斗；食物是勇气/力量的媒介。
- **可借**：下矿前不能吃某一种蘑菇；吃了的人会“被炉心听见”。

### 39. 祭祀屠宰（犹太教、伊斯兰教、多地）【高】

- **做法**：动物必须由特定的人、用特定的刀、念特定的祷词宰杀；血要放干/掩埋。
- **逻辑**：吃肉是一种暴力，必须用仪式把它变成“合法的牺牲”；血是生命，不能随便处理。
- **可借**：王都的肉必须由“持牌屠夫”宰杀；没有牌的肉是“脏肉”，吃了会变成死灵。

### 40. 动物部位等级（多地）【高】

- **做法**：不同部位给不同的人：头/舌/眼给首领/客人，内脏给猎人/战士，腿给普通人；谁吃哪块代表身份。
- **逻辑**：动物尸体是一张社会地图；分肉就是分权力。
- **可借**：营地/酒馆的“分肉”场景；玩家可以按规矩分/打破规矩。

### 41. 试毒人 / taster（古代宫廷、多地）【高】

- **做法**：国王/富人吃饭前，由仆人/狗先尝食物/酒；试毒人可能因此丧命。
- **逻辑**：权力越大，越怕毒；试毒人是“可牺牲的身体”。
- **可借**：旧王/第一公民的试毒人；主角可以当试毒人/下毒/被栽赃。

### 42. 饥荒食物（多地）【高】

- **做法**：饥荒时吃树皮、草根、泥土、皮革、骨头、甚至人；有些“饥荒食物”平时是禁忌。
- **逻辑**：饥饿会打破所有禁忌；吃什么，决定你还是不是“人”。
- **可借**：坑沿镇的“灰汤/泥饼”；玩家可以选择吃/不吃/给别人吃。

### 43. 蜂蜜防腐（古埃及、多地）【高】

- **做法**：尸体/食物被泡在蜂蜜里保存；蜂蜜被视为不朽/神圣。
- **逻辑**：蜂蜜不会腐坏，所以能对抗死亡；甜味是生命/神的味道。
- **可借**：王都的死者被泡在“炉蜜/矿石蜜”里；玩家可以尝到死者的记忆。

### 44. 盐的保存/净化（多地）【高】

- **做法**：盐用于保存食物、净化空间、驱邪、发誓；撒盐/带盐是保护。
- **逻辑**：盐能防腐，所以能对抗腐败/死亡；盐是“白色的火”。
- **可借**：王都的盐是货币/护身符/武器；盐圈可以挡住死灵。

### 45. 发酵/醉（多地）【高】

- **做法**：谷物/水果/蜂蜜发酵成酒/啤酒/醋；醉酒被视为通神/失控/真相。
- **逻辑**：发酵是“受控的腐烂”；醉让人说出真话/看见神/变成野兽。
- **可借**：酒馆的“真话酒”；喝醉的人会说旧王的秘密，但也会招来死灵。

### 46. 国王独食（多地宫廷）【中】

- **做法**：国王/首领独自吃饭，或先吃/后吃；共餐是恩宠/结盟，不是日常。
- **逻辑**：统治者的身体是特殊的；和谁吃饭，就是和谁结盟。
- **可借**：第一公民从不与外人共餐；玩家要被“赐宴”才能接近他。

### 47. 共餐座位（多地）【高】

- **做法**：谁坐哪、谁先动筷、谁给谁夹菜，都有规矩；座位是身份/关系的地图。
- **逻辑**：吃饭是社会的缩影；坐错位置就是挑衅。
- **可借**：营地/酒馆的“长桌座位”；玩家可以坐错/让座/抢座。

### 48. 供品吃掉（多地）【高】

- **做法**：献给神/祖先的食物，仪式后由信徒/家人吃掉；不吃是浪费/不敬。
- **逻辑**：神/祖先“吃”的是精神，人吃的是物质；共餐把神/人连在一起。
- **可借**：王都的“炉宴”：献给炉心的食物，仪式后分给穷人；玩家可以偷吃/下毒。

### 49. 乳/血禁忌（多地）【中】

- **做法**：某些情况下不能喝奶/血，或不能把奶/血混在一起；违反会生病/污染。
- **逻辑**：奶/血是生命液体；混错/喝错会打破身体/亲属的边界。
- **可借**：王都的“炉血/炉奶”是禁忌饮料；喝下的人会看见旧王的记忆。

## 四、身体与服饰

### 50. 剃头/断发（哀悼、成年、耻辱）【高】

- **做法**：丧期剃头/剪发，成年礼剃头/换发，罪犯/俘虏被剃头；头发被保留/埋葬/献祭。
- **逻辑**：头发是身份/生命力；剪掉它，就改变身份/切断过去。
- **可借**：主角剃头/留发改变 NPC 反应；旧王的头发是钥匙。

### 51. 寡妇丧服（多地）【高】

- **做法**：寡妇穿黑/白/麻，遮脸/剪发/不戴首饰；丧期长度代表对亡夫的忠诚。
- **逻辑**：衣服是哀悼的时钟；穿多久，就是爱多久。
- **可借**：寡妇/鳏夫的丧服颜色/长度；玩家可以通过衣服判断谁在撒谎。

### 52. 香水/香料（古埃及、中东、欧洲等）【高】

- **做法**：香水/香料用于宗教/葬礼/宫廷/诱惑；香味代表身份/神圣/洁净。
- **逻辑**：气味是看不见的衣服；香/臭决定你被当成神/人/动物。
- **可借**：王都的“炉香”掩盖尸臭/矿石病；玩家可以通过气味追踪人。

### 53. 铅/汞化妆品（古罗马、近代欧洲等）【高】

- **做法**：用铅白/朱砂/汞涂脸/嘴唇，追求白皙/红润；长期使用会中毒/脱发/死亡。
- **逻辑**：美可以是慢性自杀；白脸是贵族/不劳作的标志。
- **可借**：王都的贵族涂“炉白”面具；玩家可以识破/中毒/利用。

### 54. 身体气味禁忌（多地）【中】

- **做法**：某些气味（血、鱼、蒜、汗、经血）被视为污染/危险；接触/闻到会倒霉。
- **逻辑**：气味是边界；闻到“异类”的味道，就知道他不属于这里。
- **可借**：矿石病人有“甜/金属”气味；玩家可以闻出谁病了/谁在撒谎。

### 55. 裸体禁忌/仪式（多地）【高】

- **做法**：日常必须遮体，但仪式/浴场/审判/入会可以裸体；裸体代表平等/真相/脆弱。
- **逻辑**：衣服是社会身份；脱掉衣服，就脱掉身份/保护。
- **可借**：核心/浴场/审判要求脱下面具/衣服；玩家在裸体时无法隐藏身份。

### 56. 头发/指甲圣物（多地）【高】

- **做法**：头发/指甲被保存/埋葬/献祭/做成护身物；被认为留有本人的力量。
- **逻辑**：身体的一部分仍然“是你”；即使离开身体，也能影响你。
- **可借**：旧王的头发/指甲被分成几份，藏在不同地方；集齐才能打开核心。

### 57. 金牙/黑齿/锉牙（多地）【高】

- **做法**：牙齿被染黑/锉尖/镶金/拔掉，作为美/身份/成年/战斗的标志。
- **逻辑**：牙齿是脸的一部分；改造牙齿，就改造身份。
- **可借**：不同阵营的牙齿样式；玩家可以通过牙齿认人/认尸。

### 58. 纹身名字（波利尼西亚、日本、囚犯等）【高】

- **做法**：把名字/家族/经历/罪纹在身上；纹身是永久的身份证/族谱/判决书。
- **逻辑**：身体是档案；不能伪造/丢掉。
- **可借**：主角身上有旧王的签名纹身；不同的人能读不同的部分。

### 59. 决斗疤痕（德国学生团、军官等）【高】

- **做法**：决斗留下的疤痕被视为勇敢/荣誉，故意保留/展示；没有疤痕的人被看不起。
- **逻辑**：脸是荣誉的记录；伤疤是“我敢”的证明。
- **可借**：王都的贵族以疤痕为荣；主角可以用假疤痕/真疤痕混入。

### 60. 囚犯纹身（俄罗斯、日本等）【中】

- **做法**：囚犯/黑帮用纹身记录罪行/刑期/等级/身份；纹身是监狱里的语言。
- **逻辑**：被国家剥夺身份的人，自己造一套身份；身体是唯一的档案。
- **可借**：矿坑里的犯人用疤痕/纹身记录身份；玩家可以读/伪造/误读。

### 61. 婚礼海娜（南亚、中东、北非等）【高】

- **做法**：婚礼前在新娘/新郎手上画海娜图案；图案越复杂，越美/越有面子。
- **逻辑**：身体是婚礼的装饰/契约；海娜褪色前，新娘不用做家务。
- **可借**：王都的婚礼用“炉灰/矿墨”画手；图案是婚约/家族签名。

### 62. 死者衣物（多地）【高】

- **做法**：死者的衣服被烧掉/埋葬/送给穷人/留给继承人；有的地方必须烧，防止死者回来。
- **逻辑**：衣服是死者的第二层皮肤；处理衣服，就是处理死者。
- **可借**：主角穿着死者的衣服/面具；衣服里藏着死者的名字/债。

## 五、动物与自然

### 63. 动物新娘/新郎（多地民间故事）【高】

- **做法**：故事里人和动物结婚/生子；动物脱下皮变成人，或人披上皮变成动物。
- **逻辑**：人和动物的边界是衣服/皮；婚姻可以跨越物种。
- **可借**：旧王/炉心与“兽”的婚姻；主角可能是人/兽/炉的混血。

### 64. 狼人/兽化（欧洲民间）【高】

- **做法**：人被诅咒/咬伤/披上狼皮变成狼；月圆/夜晚/杀戮触发；银/火/名字可以破解。
- **逻辑**：人心里有兽；社会秩序压不住的时候，兽就出来。
- **可借**：矿石病人晚期“兽化”；玩家可以选择杀/治/放走。

### 65. 狂战士 / berserker（北欧）【高】

- **做法**：战士进入狂怒/出神状态，披熊皮/狼皮，不怕痛/不辨敌我；战后需要恢复/隔离。
- **逻辑**：战斗需要“变成兽”；但兽化的人不能回到正常社会。
- **可借**：四骑士/矿工的战斗状态；玩家可以触发/控制/害怕。

### 66. 使魔 / familiar（欧洲巫术）【高】

- **做法**：巫师/女巫有一只动物（猫、狗、蟾蜍、鸟）作为助手/间谍/化身；使魔有名字/契约。
- **逻辑**：动物是人的延伸；通过动物，人可以看/听/害人。
- **可借**：主角有一只“炉兽/灰鸟”作为使魔；它能进玩家进不去的地方。

### 67. 熊崇拜（阿伊努、芬兰、西伯利亚等）【中】

- **做法**：熊被视为神/祖先/客人；猎熊后有仪式，送熊的灵魂回去；熊肉被分食。
- **逻辑**：猎物也是神；吃它之前，要先把它“送回去”。
- **可借**：王都的“炉熊/矿兽”是神的化身；玩家可以杀/送/崇拜。

### 68. 蛇崇拜（印度、埃及、美洲等）【高】

- **做法**：蛇被视为神/守护者/祖先/危险；庙里有活蛇/蛇像，节日有蛇舞。
- **逻辑**：蛇介于生/死/地下/重生之间；它能蜕皮，所以能“不死”。
- **可借**：炉心/矿脉里有“蛇”；它能脱皮/换身体，是旧王的另一种形态。

### 69. 鸟占/鸡卜（罗马、非洲、东南亚等）【高】

- **做法**：看鸟的飞行/叫声/内脏，或让鸡啄米，判断神意/战争/婚事。
- **逻辑**：鸟是神的信使；天空的路径就是答案。
- **可借**：王都的“灰鸟”可以占卜；玩家可以喂/杀/追随鸟。

### 70. 火山/山神（日本、印尼、美洲等）【高】

- **做法**：火山被视为神/恶魔/祖先的家；喷发是神的愤怒/警告；有人祭/祈祷/献祭。
- **逻辑**：山是活的；它发怒，人就要负责。
- **可借**：炉心就是一座“地下火山”；玩家可以把它当神/机器/病人。

### 71. 矿灵 / knockers、kobolds（欧洲矿工民间）【高】

- **做法**：矿工相信矿井里有小人/精灵，会敲击矿壁/引导/恶作剧；听到敲击声要小心/离开。
- **逻辑**：矿井是危险/未知的；矿灵是矿工对塌方/毒气/方向的解释。
- **可借**：王都的矿道里有“敲击声”；玩家可以跟随/无视/对话。

### 72. 森林/山神（多地）【高】

- **做法**：森林/山有守护神/主人；进山要请示/献祭/遵守禁忌；迷路是神/精灵作祟。
- **逻辑**：荒野不是无人的；它有主人/规则。
- **可借**：王都外的灰海/废墟有“主人”；玩家不能随便拿/走。

### 73. 动物语言（萨满、民间故事）【中】

- **做法**：萨满/圣人/被祝福的人能听懂动物/鸟/风的话；动物会告诉人秘密/危险。
- **逻辑**：动物知道人不知道的事；听懂它们，就获得另一种知识。
- **可借**：主角能听懂炉心/矿兽/灰鸟的话；这是“同源签名”的副作用。

### 74. 猫/狗引路（埃及、欧洲、美洲等）【高】

- **做法**：猫/狗被视为引路者/守护者/死者的向导；狗能看见鬼/带路，猫能吸走最后一口气。
- **逻辑**：动物介于人/神/死者之间；它们能走人不能走的路。
- **可借**：主角有一只“引路狗/猫”；它能找到隐藏房间/死者。

### 75. 鸟/蝴蝶=灵魂（古希腊、墨西哥、斯拉夫等）【高】

- **做法**：死者灵魂变成鸟/蝴蝶/蛾；看到它们=死者回来/有话要说。
- **逻辑**：灵魂是轻的/会飞的；身体死了，它飞走。
- **可借**：王都的死者变成灰蛾/白蝶；玩家可以通过它们追踪死者。

### 76. 蜂群/狼群政治（欧洲、蒙古等）【中】

- **做法**：蜂群/狼群被用来比喻国家/军队/家族；蜂王/狼王是统治者，工蜂/狼群是臣民。
- **逻辑**：自然秩序证明社会秩序；人应该像蜂/狼一样服从。
- **可借**：新国的宣传用“蜂群/狼群”比喻公民；旧国用“炉火/家”比喻。

### 77. 圣林（欧洲、印度、非洲等）【高】

- **做法**：一片森林/树林被视为神/祖先的居所，不能砍伐/狩猎/进入；违反会招灾。
- **逻辑**：有些地方不属于人；保留它，是为了让神/祖先有地方住。
- **可借**：王都附近有一片“不能砍的灰林”；玩家可以砍/保护/发现里面的墓。

## 六、儿童游戏与教育

### 78. 过家家（多地）【高】

- **做法**：孩子扮演父母/孩子/客人，用玩具/树叶/石头做饭/结婚/葬礼；模仿成人社会。
- **逻辑**：游戏是预演；孩子通过玩，学会角色/规矩。
- **可借**：孤儿帮玩“过家家”，模仿城门/营地/核心；玩家可以从游戏里看到他们的恐惧/希望。

### 79. 战争游戏（多地）【高】

- **做法**：孩子用木棍/石头/泥巴打仗，分敌我/攻守/俘虏；有时真的受伤/结仇。
- **逻辑**：战争被游戏化；孩子提前学习暴力/阵营/荣誉。
- **可借**：坑沿镇的孩子玩“打炉心”的游戏；玩家可以加入/旁观/利用。

### 80. 玩偶（多地）【高】

- **做法**：玩偶被当成孩子/朋友/神/死者；有名字/衣服/家；坏了要“治”/“埋”。
- **逻辑**：玩偶是人的替身；对它好/坏，会反映/影响现实。
- **可借**：主角找到一个玩偶，里面藏着死者的名字/头发；玩偶会“说话”。

### 81. 木偶/傀儡戏（多地）【高】

- **做法**：用线/手/棍操纵木偶演戏；木偶可以演神/人/动物/死者；演师在幕后。
- **逻辑**：人也可以被操纵；谁在幕后，谁就是神/命运。
- **可借**：王都的“傀儡戏”演旧王/四骑士；玩家发现演师是核心/回声。

### 82. 抓子/羊拐（多地）【高】

- **做法**：用石子/羊拐/骨头抛接/抓取；有固定的顺序/花样；也用于占卜/赌博。
- **逻辑**：手眼协调/命运；骨头的正反/组合可以读成吉凶。
- **可借**：矿工用矿石/指骨玩“抓子”；玩家可以通过游戏占卜/赢钱。

### 83. 跳房子（多地）【高】

- **做法**：在地上画格子，单脚/双脚跳过去；格子有时是迷宫/天堂/地狱。
- **逻辑**：空间被画成路线；跳错就“死”；游戏是小型朝圣/审判。
- **可借**：王都的地面有“跳房子”格子；玩家要按顺序跳，否则触发陷阱。

### 84. 跳绳歌（多地）【高】

- **做法**：孩子边跳边唱；歌词有时编码历史/瘟疫/政治/婚姻；节奏决定动作。
- **逻辑**：歌是口述历史；孩子不知道歌词的意思，但一直在传。
- **可借**：孤儿唱一首“炉心歌”；歌词倒过来听，是旧王的留言/警告。

### 85. 捉迷藏（多地）【高】

- **做法**：一个人蒙眼/数数，其他人躲；被找到的人成为下一个“鬼”。
- **逻辑**：躲藏/寻找/替换；鬼是“被抓住的人”。
- **可借**：王都的孩子玩捉迷藏，真的有人失踪；玩家发现“鬼”是死灵。

### 86. 摸瞎子（多地）【高】

- **做法**：一个人蒙眼摸人；摸到谁，谁就输/成为下一个；蒙眼的人被视为“鬼/瞎子”。
- **逻辑**：看不见的人有另一种“看见”；触摸是传染/识别。
- **可借**：盲眼的孤儿/先知玩“摸瞎子”；他摸到主角，说“你身上有旧王的味道”。

### 87. 棋盘游戏（多地）【高】

- **做法**：棋/骰/格子游戏模拟战争/宇宙/命运；棋子有等级/走法；输赢有时被当成占卜。
- **逻辑**：世界是一个棋盘；玩家/神/命运在下棋。
- **可借**：旧王的“炉心棋”；玩家可以通过下棋理解四骑士的职能/核心的规则。

### 88. 骰子（多地）【高】

- **做法**：用骨头/木头/石头做骰子，掷出点数决定输赢/命运/神意；赌博/占卜/分财产都用。
- **逻辑**：随机是神的发言；掷骰子是把决定交给命运。
- **可借**：王都的“炉心骰子”；玩家可以用它决定谁下矿/谁被献祭。

### 89. 纸牌（多地）【高】

- **做法**：纸牌用于游戏/赌博/算命；花色/点数/人物有象征意义；洗牌/切牌/发牌有仪式。
- **逻辑**：牌是命运的模型；洗牌把秩序打乱，发牌把命运分给人。
- **可借**：酒馆的“旧王牌”；每张牌是一个死者/骑士/灾难；玩家可以用牌占卜/作弊。

### 90. 童谣（多地）【高】

- **做法**：孩子唱短歌/韵文，内容可能是历史/政治/瘟疫/讽刺；大人不唱，孩子传。
- **逻辑**：孩子是口述历史的保存者；他们不懂，但记得。
- **可借**：孤儿唱“四骑士童谣”；歌词里藏着旧王/新国的真相。

### 91. 学校/背诵（多地）【高】

- **做法**：孩子背诵经典/经文/历史；老师用体罚/重复/比赛；背诵是进入上层/宗教的途径。
- **逻辑**：记忆是权力；谁能背，谁就能进入系统。
- **可借**：王都的“读经班”背新国官修史书；玩家发现孩子背的版本和地下碑文不一样。

### 92. 风筝/斗风筝（中国、阿富汗、印度等）【高】

- **做法**：放风筝/斗风筝，用玻璃线割断对方的风筝线；赢家捡/抢断线风筝。
- **逻辑**：天空是战场；线是刀；风筝是面子/运气。
- **可借**：坑沿镇的孩子在灰海上放“骨风筝”；线可以割人/传信/测量风。

### 93. 陀螺（多地）【高】

- **做法**：用绳子/手转陀螺，看谁转得久/撞倒对方；陀螺有响声/颜色/形状。
- **逻辑**：旋转=世界/命运；停下来=死亡/失败。
- **可借**：王都的“炉心陀螺”；转得越久，炉心越稳；孩子用它占卜。

## 七、疾病与医疗

### 94. 隔离 / quarantine（中世纪欧洲、多地）【高】

- **做法**：瘟疫期间，船只/旅客/病人被隔离 40 天（quarantine 来自 quaranta giorni）；城门/房子被标记/封锁。
- **逻辑**：疾病通过接触/空气传播；隔离是“用墙买时间”。
- **可借**：坑沿镇发现矿石病时封锁矿道/城门；玩家可以遵守/偷跑/救人的。

### 95. 麻风病院 / leprosarium（中世纪欧洲）【高】

- **做法**：麻风病人被隔离在城外/病院，穿特定衣服/摇铃/不能进教堂；有时举行“活人葬礼”。
- **逻辑**：病是污染/罪；病人是社会性死人，但教会仍要照顾。
- **可借**：矿石病人被赶到镇外“玻璃村”；玩家可以送药/放火/偷东西。

### 96. 鸟嘴医生面具 / plague doctor（17 世纪欧洲）【高】

- **做法**：医生穿长袍/手套/帽子，戴鸟嘴面具，鸟嘴里塞香料/草药，防止“瘴气”。
- **逻辑**：面具是防护/恐吓；医生看起来像鸟/死神。
- **可借**：王都的“炉医”戴鸟嘴/矿工面具；玩家可以通过面具认医生/冒充医生。

### 97. 放血 / bloodletting（古希腊-近代欧洲）【高】

- **做法**：用刀/水蛭/杯吸放血，平衡体液；几乎什么病都放血。
- **逻辑**：病是体液过多/失衡；放掉坏血，人就恢复。
- **可借**：王都的“炉医”给矿石病人放血/放晶；玩家可以接受/拒绝/利用。

### 98. 四体液 / humors（古希腊-近代欧洲）【高】

- **做法**：人体有血/痰/黄胆/黑胆四种体液；失衡导致疾病/性格；放血/催吐/泻药调整。
- **逻辑**：身体是一个小宇宙；健康是平衡，疾病是失衡。
- **可借**：王都的“炉火/灰/矿/盐”四体液；不同体质的人对炉心反应不同。

### 99. 草药 / herbal medicine（多地）【高】

- **做法**：用植物/根/花/树皮治病；采集/炮制/配方有规矩；药师/巫医/祖母传承。
- **逻辑**：自然里有解药；知道植物的人掌握生命。
- **可借**：坑沿镇的“灰药师”；玩家可以采药/配药/误认毒草。

### 100. 签名说 / doctrine of signatures（欧洲）【中】

- **做法**：植物的形状/颜色/生长环境暗示它能治什么病：肺形叶治肺，黄汁治肝，核桃治头。
- **逻辑**：神在植物上写了“签名”；自然是一本可读的书。
- **可借**：王都的“矿草”外形像器官/炉心；玩家可以按“签名”找解药/被误导。

### 101. 瘴气 / miasma（古代-近代）【高】

- **做法**：疾病来自腐败的空气/沼泽/尸体/污水；用香料/火/口罩/搬家防瘴气。
- **逻辑**：坏空气=坏病；气味是病因。
- **可借**：王都的火山灰/炉烟被当成瘴气；玩家发现真正的病因是矿石/水。

### 102. 接触传染 / contagion（多地）【高】

- **做法**：疾病通过接触病人/尸体/衣服/物品传播；隔离/焚烧/洗手/换衣。
- **逻辑**：病可以“粘”在东西上；接触是危险的。
- **可借**：矿石病人的衣服/血/泪会传染；玩家要决定烧/藏/带走。

### 103. 接种/牛痘 / vaccination（近代欧洲）【高】

- **做法**：用牛痘/天花痂接种，让人轻微感染，获得免疫；早期被反对/恐惧。
- **逻辑**：以毒攻毒；让自己得一点病，避免大病。
- **可借**：王都的“炉种”：让健康人接触少量矿石/炉灰，获得抗性；失败的人变成晶尸。

### 104. 截肢 / amputation（古代-近代）【高】

- **做法**：锯掉坏死的肢体，止血/烧灼/包扎；没有麻药/消毒，死亡率高。
- **逻辑**：舍部分保整体；身体可以修理/丢弃。
- **可借**：矿工被矿石吃掉手脚；玩家可以选择截肢/保留/换机械义肢。

### 105. 环钻/开颅 / trepanation（史前-多地）【高】

- **做法**：在头骨上钻/刮一个洞，放出“坏血/恶灵/压力”；有的病人活了下来（骨头愈合）。
- **逻辑**：脑袋里的病可以通过一个洞出来；洞是灵魂/压力的出口。
- **可借**：王都的“开颅师”给疯人/先知开洞；玩家可以看见/听见另一个世界。

### 106. 信仰治疗/国王触摸（多地）【高】

- **做法**：通过祈祷/圣物/国王触摸/朝圣治病；病人相信/真的好转（安慰剂）。
- **逻辑**：病不只是身体，也是信仰/关系；谁有神圣力量，谁就能治。
- **可借**：旧王的遗物/面具可以“治”矿石病；玩家可以信/揭穿/利用。

### 107. 医院（中世纪修道院、伊斯兰世界等）【高】

- **做法**：修道院/清真寺/慈善机构收治病人/穷人/朝圣者；有病房/药房/浴室/厨房。
- **逻辑**：照顾病人是宗教义务/城市荣誉；医院是“灵魂+身体”的修理厂。
- **可借**：坑沿镇的“灰屋”收治矿石病人；玩家可以帮忙/抢劫/发现秘密。

### 108. 瘟疫坑 / plague pit（中世纪欧洲等）【高】

- **做法**：瘟疫死者被大量埋在一个坑里，撒石灰/覆土；没有名字/墓碑。
- **逻辑**：死人太多，个人葬礼不可能；集体埋葬是应急/遗忘。
- **可借**：王都地下有“无名坑”；玩家可以在里面找到身份牌/名字/线索。

### 109. 解剖剧场 / anatomy theater（近代欧洲）【高】

- **做法**：公开解剖尸体，学生/医生/付费观众围观；解剖者/讲解者表演。
- **逻辑**：身体是知识；切开它，才能知道它怎么工作。
- **可借**：王都的“炉解剧场”：公开拆解死灵/矿石病人；玩家可以看/阻止/偷尸体。

### 110. 水井/下水道（古代城市）【高】

- **做法**：城市依赖井/泉/水道；污水/尸体/矿石污染水源；井是公共/神圣/危险的地方。
- **逻辑**：水是生命，也是疾病；谁控制水，谁控制城。
- **可借**：坑沿镇的唯一水井被矿石污染；玩家可以找新水源/净化/抢水。

## 八、战争与俘虏

### 111. 征兵 / levy（古代-近代）【高】

- **做法**：国家/领主按户/人口抽壮丁；逃避者被罚/抓/没收财产；征兵官腐败。
- **逻辑**：国家需要身体；谁有权力，谁就能拿走你的时间/命。
- **可借**：新国/军阀在坑沿镇征兵；玩家可以逃/替人/被卖。

### 112. 雇佣兵 / mercenaries（古代-近代）【高】

- **做法**：外国/职业士兵为钱打仗；忠诚不稳定，谁付钱跟谁；有时抢劫雇主。
- **逻辑**：战争是生意；没有钱，就没有兵。
- **可借**：坑沿镇的“灰团”雇佣兵；玩家可以加入/雇佣/背叛。

### 113. 赎金 / ransom（中世纪、海盗、战争）【高】

- **做法**：俘虏被标价，家属/国家付钱赎回；付不起就被杀/卖为奴。
- **逻辑**：人的命有价格；战争是投资/生意。
- **可借**：玩家/NPC 被俘虏；玩家可以凑钱/交换/放弃。

### 114. 假释 / parole（近代战争）【高】

- **做法**：战俘发誓不再参战/不逃跑，被释放回家；违反誓言会被处死/羞辱。
- **逻辑**：誓言可以代替监狱；荣誉/信用是战争的规则。
- **可借**：玩家被抓后发誓不再下矿；违反会被城门机器/骑士追杀。

### 115. 俘虏交换（古代-近代）【高】

- **做法**：双方按等级/人数交换俘虏；有时一个军官换几个士兵；交换仪式公开。
- **逻辑**：人是可计算的筹码；交换维持战争的“文明”规则。
- **可借**：玩家可以用一个 NPC 换另一个；选择谁值得救。

### 116. 十一抽杀 / decimation（罗马）【高】

- **做法**：部队怯战/叛变时，随机抽十分之一的士兵处死；其余人观看/执行。
- **逻辑**：集体惩罚让每个人负责；恐惧维持纪律。
- **可借**：矿工/士兵逃跑时，镇上抽签处死十分之一；玩家可以操纵抽签/反抗。

### 117. 屠城 / sack（古代-近代战争）【高】

- **做法**：城破后，士兵被允许抢劫/强奸/屠杀若干天；这是军饷/威慑/恐怖。
- **逻辑**：城是战利品；平民是士兵的报酬。
- **可借**：王都陷落时被屠城；玩家可以逃/藏/救人/加入。

### 118. 战利品/首级（多地）【高】

- **做法**：割下敌人的头/耳朵/头皮/手，作为战功/证据/货币；有时公开示众。
- **逻辑**：身体是战功的收据；没有证据，就没有奖赏。
- **可借**：矿工/雇佣兵割“晶尸”的手/头换赏金；玩家可以阻止/利用。

### 119. 凯旋式 / triumph（罗马）【高】

- **做法**：胜利将军率军队/俘虏/战利品游行进城，接受欢呼；俘虏可能被处死。
- **逻辑**：胜利需要表演；城市通过观看确认权力。
- **可借**：新国/军阀的“凯旋式”；玩家可以在游行中刺杀/救人/被展示。

### 120. 攻城/围城（古代-近代）【高】

- **做法**：包围城市，切断粮食/水/援军；用云梯/撞门/地道/投石机；城内饿死/吃马/投降。
- **逻辑**：城是身体；饿它/打它/等它死。
- **可借**：坑沿镇被围；玩家可以守/突围/谈判/投降。

### 121. 坑道战 / sappers（古代-近代）【高】

- **做法**：士兵挖地道到城墙下，支撑/放火/炸塌；守军挖反地道/听声音/灌水。
- **逻辑**：地下是战场；墙不是不可破的。
- **可借**：王都的地下通道/矿道就是战场；玩家可以挖/听/堵/放毒气。

### 122. 随军人员 / camp followers（古代-近代）【中】

- **做法**：军队后面跟着商人/妓女/家属/厨师/铁匠/乞丐；他们提供后勤/服务/情报。
- **逻辑**：军队是一座移动城市；没有随军人员，军队会饿/病/逃。
- **可借**：坑沿镇的“灰团”后面跟着一整个市场；玩家可以在那里买/卖/打听。

### 123. 逃兵 / deserters（古代-近代）【高】

- **做法**：士兵逃跑，被抓后处死/鞭打/烙印；逃兵躲进森林/城市/边境。
- **逻辑**：逃跑是死罪；但留下来也可能死。
- **可借**：逃兵躲在坑沿镇；玩家可以藏/卖/举报/招募。

### 124. 退伍兵 / veterans（古代-近代）【高】

- **做法**：老兵退役后领土地/钱/特权，或成为乞丐/佣兵；身上的伤/纹身/习惯还在。
- **逻辑**：战争结束，人没有结束；社会不知道怎么安置会杀人的人。
- **可借**：坑沿镇的老兵/矿工；玩家可以听他讲旧战争/雇他/被他抢。

### 125. 战犯审判 / war crimes tribunal（近代）【高】

- **做法**：战后审判战犯/叛徒/合作者；公开审判/处决/赦免；证据/证人/政治交易。
- **逻辑**：胜利者写法律；正义/复仇/表演混在一起。
- **可借**：新国灭亡后，旧地审判“第一公民”的官员；玩家可以作证/包庇/利用。

### 126. 和约 / peace treaty（古代-近代）【高】

- **做法**：战后签订条约，割地/赔款/交换俘虏/通婚；条约写在纸/石/碑上。
- **逻辑**：战争结束需要一张纸；纸比人记得久。
- **可借**：旧王/新国的和约刻在炉心/城门上；玩家可以读/改/毁。

### 127. 缓冲区 / buffer state（帝国边境）【高】

- **做法**：两个大国之间留一个小国/无人区，作为缓冲；当地人被牺牲/利用。
- **逻辑**：边界不是线，是地带；住在那里的人不属于任何一方。
- **可借**：坑沿镇就是旧国/新国之间的缓冲区；玩家不属于任何国家。

## 九、深挖示例：一条风俗怎么变成一场戏

### 例 1：冷水神判 → 核心的“验证”

- **表面**：主角被要求把手/脚浸入炉心的冷水/熔岩；沉下去/没被烧伤=无罪。
- **当地原因**：水/火会拒绝罪人；核心只接受“干净”的签名。
- **世界真正原因**：冷水里含矿石/炉灰，只有同源者能承受；所谓神判，其实是签名检测。
- **戏**：玩家可以选择“信神判/作弊/拒绝”；如果作弊，核心可能仍然通过，但回声会记录“作弊”。

### 例 2：尸体出血 → 绞索房间的指认

- **表面**：玩家靠近吊死的遗骸，尸体流出黑血/黑泪；镇上的人说“死者在指认凶手”。
- **当地原因**：死者自己会说话；血是最后的证词。
- **世界真正原因**：尸体里的矿石/炉灰遇到同源签名会反应；不是鬼，是化学。
- **戏**：玩家可以相信/不信；如果带某个 NPC 来，尸体反应更强，玩家要判断谁是凶手/谁是同源者。

### 例 3：年金/tontine → 深潜合同

- **表面**：一群矿工共同出资签“深潜合同”，最后一个活着的人继承矿脉/抚恤金。
- **当地原因**：大家互相帮助/共同冒险；活到最后的人替死者照顾家人。
- **世界真正原因**：这是一场合法的“等别人死”的赌博；有人开始制造事故。
- **戏**：玩家可以加入/调查/破坏；每个矿工都有动机，死者名单就是线索。

## 十、怎么用

1. **先问“这条风俗在解决什么问题”**：分财产、处理尸体、控制性、维持秩序、解释灾难。
2. **再问“谁受益、谁付代价”**：风俗从来不是中立的；一定有阶级/性别/年龄的差异。
3. **最后换表面**：把真实文化里的神/祖先/国王，换成炉心/旧王/签名/矿石。
4. **不要把刑罚/疾病/战争当奇观**：写痛苦，是为了让玩家看见制度，不是为了刺激。
5. **标注可信度**：`【中】/【待核】` 的条目，写进游戏前再查一次。
