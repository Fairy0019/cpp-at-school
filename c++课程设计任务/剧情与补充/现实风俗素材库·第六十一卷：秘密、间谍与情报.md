# 第六十一卷：秘密、间谍与情报

> 状态：素材收集 v0.2（详细版），2026-11-26。
>
> 说明：每条给“内容 / 出处 / 原文要点”，不再写“怎么用”。

### 1. 摩萨德 / Mossad（以色列，1949–）【高】

- **内容**：以色列对外情报机构；暗杀/绑架/渗透/技术/救援；目标包括纳粹战犯/阿拉伯国家/伊朗/恐怖组织；以“大胆/复仇/先发制人”闻名。
- **出处**：Mossad 研究/前特工回忆（如 Ostrovsky, *By Way of Deception*, 1990；有争议，标【中】）。
- **原文/要点**：摩萨德的叙事常把“情报/暗杀/救援”写成国家生存/犹太复仇；批评者指出它的行动/伦理/政治后果常被“英雄故事”掩盖。

### 2. 维基解密 / WikiLeaks（全球，2006–）【高】

- **内容**：匿名泄密平台/大规模文件/外交电报/战争日志/媒体合作/追捕；透明/权力/危险；阿桑奇/厄瓜多尔使馆/引渡。
- **出处**：Andy Greenberg, *WikiLeaks: Inside Julian Assange’s War on Secrecy* (PublicAffairs, 2012)。
- **原文/要点**：这本书记录 WikiLeaks 的崛起/泄密/争议：它把“透明”当成武器，也暴露了泄密/隐私/国家安全的灰色地带。

### 3. 斯诺登 / Snowden（美国/全球，2013）【高】

- **内容**：NSA 承包商/大规模监控/棱镜计划/泄密/逃亡/香港/莫斯科/庇护；隐私/安全/权力；英雄/叛徒争议。
- **出处**：Edward Snowden, *Permanent Record* (Metropolitan Books, 2019)。
- **原文/要点**：斯诺登的自述把监控写成“日常/隐形/无限”的权力：他不是“反安全”，而是反对秘密/无授权的数据收集；他的选择/流亡/争议也是故事的一部分。

### 4. 吹哨人 / whistleblowers（全球）【高】

- **内容**：内部/举报/媒体/法律/报复/保护；美国/全球；真相/权力/危险；吹哨人常被孤立/解雇/起诉。
- **出处**：Whistleblower 研究（具体版本待核，标【中】）。
- **原文/要点**：吹哨人的核心矛盾是“忠诚”与“公共利益”：他们揭露组织/政府的错误，却常被当成叛徒；保护制度/媒体/公众支持决定他们是英雄还是受害者。

### 5. 加密/端到端 / encryption（全球）【高】

- **内容**：密码/密钥/软件/隐私/犯罪/政府；从军事/外交到互联网/手机；端到端加密让通信“只有两端能读”。
- **出处**：Simon Singh, *The Code Book: The Science of Secrecy from Ancient Egypt to Quantum Cryptography* (Fourth Estate, 1999)。
- **原文/要点**：Singh 把加密写成“秘密/数学/权力”的历史：谁掌握密码，谁掌握信息；现代加密让政府/犯罪/隐私的平衡更紧张。

### 6. 暗杀/定点清除 / assassination（全球）【高】

- **内容**：特工/无人机/毒/枪/政治/法律；美国/以色列/俄罗斯/全球；秘密/暴力/权力；定点清除/法外处决争议。
- **出处**：Assassination 研究（具体版本待核，标【中】）。
- **原文/要点**：暗杀把“战争/情报/政治”压缩成一次暴力行动：它可能改变历史/制造报复/破坏法律；谁下令/谁执行/谁被追究，决定它是“反恐”还是“谋杀”。

### 7. 政变 / coup d’état（全球）【高】

- **内容**：军队/情报/媒体/街头/宪法/外国；非洲/拉美/中东；权力/暴力/政治；政变常以“拯救国家/恢复秩序”为名。
- **出处**：Edward Luttwak, *Coup d’État: A Practical Handbook* (Harvard University Press, 1968)。
- **原文/要点**：Luttwak 把政变写成“小集团夺取国家机器”的技术：控制首都/广播/交通/领导人，就能用最小暴力改变政权；这本书本身也引发伦理/安全争议。

### 8. 黑狱 / black sites（全球，2000s–）【高】

- **内容**：秘密监狱/引渡/酷刑/无法律/否认；美国/全球；安全/正义/权力；CIA 黑狱/关塔那摩/“强化审讯”。
- **出处**：Mark Mazzetti, *The Way of the Knife: The CIA, a Secret Army, and a War at the Ends of the Earth* (Penguin, 2013)。
- **原文/要点**：Mazzetti 记录美国在 9·11 后的秘密战争/黑狱/无人机：国家把拘留/审讯/杀戮移到法律之外，制造了问责/人权/记忆的黑洞。
