# 剧情与补充

本目录归档《沉没王都》的剧情文档与补充设定，方便和代码一起查看、追溯。

## 文档

- **沉没王都剧情设计大纲.docx**  
  早期剧情大纲与工作稿。四骑士的真实身份在文档中保留为开放谜团，适合查看最初的构思和分幕方向。

- **沉没王都故事逻辑完善稿.docx**  
  当前采用的剧情因果参考。明确了地心炉、三灾、旧国王、血脉权限和四骑士守护单元的关系统一设定。

## 当前实现采用的口径

- 三灾是地心炉失稳造成的非周期性灾难，没有固定顺序。
- 地震撕开山体后会引发火山活动，火山灰长期笼罩城市；居民外出戴面具，身份牌仍用于登记与存档。
- 当前王国不知道地心炉存在，不把灾难解释成阴谋。
- 机械门卫只执行登记与放行，发给主角临时身份牌，不识别血脉。
- 主角在核心门前通过旧王朝签名获得访问权限；身份牌上的物种是自报身份。
- 四骑士是旧王朝的四个守护单元，后世幸存者把它们误传成“天启四骑士”。
- 首版实现封存骑士一名首领，另外三尊处于停摆状态，留作后续扩展。
- 已实现地面枢纽（灰烬街道、路灯、左右移动、集市 / 废墟营地 / 酒馆 / 封闭高塔）和见闻系统。
- 地下第 5 层有一个可选隐藏房间：先祖遗骸。只持久化 `ancestor.found` / `ancestor.read` 等特殊房间标记，不保存所有地下层数。
- 结局分为熄灭、稳定、摧毁和拒绝介入；结局编号保存在 `story_progress.sav`。
