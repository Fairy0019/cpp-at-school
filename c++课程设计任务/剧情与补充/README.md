## 历史背景（摘要）

- 古国（旧国）辽阔但中央无力，旧王由各方推举而治，不是世袭帝国。
- 古国更接近松散的荣誉共同体：极重名誉的贵族掌握军队，把平民视为财产/生命；王是每年确认的“贡献最大者”尊称，没有宫廷礼仪，贵族不轻易自立为王。
- 旧国富裕，平民的学习和生活由贵族保障，可向贵族或议会申请研究经费和材料；社会评论压力极大，人人自负，研究失败会带来强烈愧疚和公开批评。
- 王的权力主要是礼仪与外交，实际权力由议会行使；晚期与外部势力/怪物长期战争，贵族死得差不多了，议会与资助网络随之崩溃。
- 古国延续数千年，地形环境逐渐改善；地心炉在旧国晚期才出现。人造人技术更早出现，但极难制造、数量很少，古国曾讨论他们的“人权”。
- 末代旧王最初因治理灾害、整顿矿务等贡献被尊为王，后来因炉心工程以“非常时期”紧急连任，实际上成为终身执政；旧王朝的宪制被一件太大的贡献撑死。
- 炉心运行后析出矿石，第一批矿工患病；旧王见过病人，因愧疚和责任在停炉后出走，带走大批贵族。部分贵族和平民留下，王位空置。
- 贵族就是军队；他们一走，旧地失去军队。散人政府依赖佣兵，佣兵自重、土匪化；反抗外族的地方武装/边地豪强形成影子政府，延续四代，第五代“骡”清洗散人政府，建立新国。
- 新国的合法性来自“我们没有走”：它把旧王的出走说成背叛，把旧王的真实失败放大成全部真相。
- 新国并不正统：前四代是抵抗政权/影子政府；第五代“骡”清洗散人政府，正式建立新国，成为第一任第一公民；新国本身七代第一公民，加上前四代合计十一代；实际是集体领导或个人领导的独裁。
- 旧民怀念旧王；新国官修史书称旧王为暴君，但这一说法不可全信。
- 新国晚期衰败、采矿失控，逐步灭亡。
- 民间误传的“四灾”不是天灾，也不是四骑士造成的，而是新国政治下出现的征服、战争、饥荒、死亡，被官方文件隐瞒、嫁祸。
- 纪年分为旧历（古国）、残历（旧王离开起）、新历（第五代建国起）；具体换算与年份待定。
- 旧王无嗣；主角是人造人，与旧王“本质同源”，核心的呼唤来自同源签名，不是后代血脉。主角的制造者、本质和意识形成方式待定。
- 主角在核心面对的是旧王留下的“回声”，不是旧王本人；回声会问“你恨我吗”，四个结局是四种回答，最后可以选择如何称呼造物主。
- 旧王已死约一千年；新国已灭亡；游戏当下在新国灭亡后，地面是无国家的拾荒镇。
- 凡人寿命一般 100—140 岁，理论极限 200 岁；一千年约七到十代人。
- 当下的身份群体：拾荒者、旧国遗民、新国遗民、流亡贵族后裔、孤儿帮、矿石病人、商人、传教士。
- 身份的四层：身份牌、签名、名字、面具。
- 主角的身份悬置：主角自己也不知道自己是谁；游戏不确认他是旧王亲手造的、后期国家造的，还是别的什么。
- 宗教建议：不确认有神，但有旧国的公民宗教/祖先崇拜、新国的第一公民崇拜、当下的碎片化信仰；死灵不是神迹。
- 新国政体参考罗马元首制 + 《基地》中“骡”的个人化政权：第一公民、元老院、军团、禁卫军、census/身份牌；集体领导与个人领导反复循环。
- 合法性暗线：“替换/窃国”事件——如果统治者被外族秘密替换，政府还合法吗？主角的身份悬置与国家的合法性是同一个问题。
- 已确定：“骡”是第五代领袖、第一任第一公民、新国建立者；前四代是抵抗政权；第五代清洗散人政府；新国本身七代第一公民。“替换”事件真实发生过也被夸大；新国有公民宗教，没有神学/人格神。
- 死灵是炉心/矿石/葬仪失效的“残留模式”，不是神迹；分为灰行者、回声死者、晶死者。
- 身份牌是国家的记忆（census/读卡机/黑市/伪造）；面具是脸的社会；坑沿镇以物易物，矿石碎片是硬通货。
- 人文风俗采用“反常识解释”：双胞胎先出生的是妹妹（姐姐让她先出去探路）、墓碑是镇压死者的石头、新生儿继承最近死者的名字、偷名字比偷东西重、婚姻是换债、待客是借名字、年龄从第一场灰暴算起、门低槛高镜朝下、摇篮曲倒着唱、第一口给火/死者。
- 地心炉从未真正熄灭，仍悬浮于熔岩之上；矿石在旧王时代已经出现，几百年后长成散热层，又因新国采矿而被削薄。
- 矿石可提供能量，但会导致矿石病；具体症状、传播和治疗方法待定。
- 日常活动中会插入随机人物事件，例如帮助他人（可能是诈骗）、组队申请（可能背叛）、孤儿与身份等。

## 当前实现采用的口径

> 这一节描述的是**当前游戏代码**的旧口径（新国仍在），不是修订后的剧情。修订后的剧情以 `历史与政权.md` 和 `新国灭亡后的世界.md` 为准。

- 三灾是地心炉失稳造成的非周期性灾难，没有固定顺序。
- 地震撕开山体后会引发火山活动，火山灰长期笼罩城市；居民外出戴面具，身份牌仍用于登记与存档。
- 新国官方不承认地心炉的存在；矿务体系知道矿石异常，但相关真相被分层隐瞒。
- 机械门卫只执行登记与放行，发给主角临时身份牌，不识别旧王朝的同源签名。
- 主角在核心门前通过旧王朝的同源签名获得访问权限；身份牌上的物种是自报身份。
- 四骑士是旧王朝的四个守护单元：控制、防卫、配给、封存；后世幸存者把它们误传成“天启四骑士”征服、战争、饥荒、死亡。
- 旧王无嗣；主角是人造人，与旧王本质同源，不是旧王的后代。主角的制造者和本质待定。
- 地心炉从未真正熄灭，旧王的“停炉”只是切断输出/封存；矿石在旧王时代已经出现，几百年后长成散热层，又因新国采矿而被削薄。
- 矿石可提供能源，但会导致矿石病；矿石病作为长期特殊疾病，后续再定症状与规则。
- 首版实现封存骑士一名首领，另外三尊处于休眠/停摆状态，留作后续扩展。
- 已实现地面枢纽（灰烬街道、路灯、左右移动、城门 / 商店 / 废墟营地 / 酒馆 / 封闭高塔）和见闻系统。
- 地面商店老板是考古爱好者：地下刻纹石板可带来解读，收购后给商店九折优惠；拾荒者和游商拒收。
- 地下第 5 层有一个可选隐藏房间：先祖遗骸。只持久化 `ancestor.found` / `ancestor.read` 等特殊房间标记，不保存所有地下层数。
- 结局分为熄灭、稳定、摧毁和拒绝介入；结局编号保存在 `story_progress.sav`。
