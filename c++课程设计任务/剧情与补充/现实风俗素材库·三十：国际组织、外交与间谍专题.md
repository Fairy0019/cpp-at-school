# 现实风俗素材库·三十：国际组织、外交与间谍专题

> 状态：素材收集 v0.1，2026-11-26。
>
> 用途：收现代国际组织/外交/间谍/边境/人道主义的制度与仪式，每条给“具体案例 + 做法 + 逻辑 + 可借 + 出处”。
>
> 说明：
> - 这一卷偏“现代国家/国际体系”，不是传统民俗；但同样是“人怎么处理陌生人/冲突/秘密”的素材。
> - 出处以历史研究/UN/国际法/新闻为主；百科只当入口。
> - `【高】` = 学术/UN 来源较可靠；`【中】` = 来源较泛，写进游戏前再核；`【待核】` = 只当线索。
> - 涉及战争/间谍/难民/制裁的内容，写作时不要猎奇；借制度逻辑，不借痛苦表面。

## 一、联合国与外交

### 1. 联合国安理会 / UN Security Council（全球，1945–）【高】

- **做法**：15 个成员/5 常任/否决权/决议/制裁/维和/谈判；大国/小国/联盟；走廊/闭门/公开。
- **逻辑**：权力=“席位/否决/联盟”；谁有否决权，谁能否决世界。
- **可借**：王都的“灰安理会/炉席”；玩家可以否决/被否/游说；权力是“席位/规则/联盟”。
- **出处**：UN Security Council 研究（如 *The UN Security Council* 相关论著；具体版本待核）。

### 2. 联合国维和 / peacekeeping（全球，1948–）【高】

- **做法**：蓝盔/观察员/停火/缓冲区/巡逻/保护平民/选举；冲突国/邻国/大国；失败/性侵/政治。
- **逻辑**：维和=“中立的武力/希望/羞辱”；谁派/谁被派，代表权力/责任。
- **可借**：坑沿镇的“灰蓝盔/炉卫”；玩家可以加入/被拒/被利用；维和是“和平/暴力/政治”。
- **出处**：Peacekeeping 研究（具体版本待核）。

### 3. 日内瓦公约 / Geneva Conventions（全球，1864/1949）【高】

- **做法**：战争规则/伤兵/战俘/平民/红十字/标志/医院/禁止酷刑；国家/军队/国际法；违反/审判。
- **逻辑**：战争也需要“规则/人性”；谁违反，谁被审判。
- **可借**：王都的“灰公约/炉法”；玩家可以遵守/违反/被审；公约是“战争/人性/法律”。
- **出处**：Geneva Conventions 研究（如 *The Geneva Conventions* 相关论著；具体版本待核）。

### 4. 大使馆/外交豁免 / embassy & diplomatic immunity（全球）【高】

- **做法**：使馆/国旗/签证/庇护/间谍/宴会/谈判；驻在国/派遣国/国际法；驱逐/断交/围攻。
- **逻辑**：使馆=“本国领土/例外空间”；谁进/谁被拒，代表主权/权力。
- **可借**：王都的“灰使馆/炉地”；玩家可以躲/被围/被驱逐；使馆是“主权/避难/间谍”。
- **出处**：Diplomatic immunity 研究（具体版本待核）。

### 5. 峰会/合影 / summit & photo op（全球，20 世纪–）【中】

- **做法**：领导人/红毯/握手/合影/联合声明/晚宴/礼物/翻译；媒体/安保/礼仪；成功/失败/表演。
- **逻辑**：外交=“表演/信号/关系”；谁站中间/谁握手，代表权力/和解。
- **可借**：王都的“灰峰会/炉会”；玩家可以看/被拍/被利用；峰会是“表演/权力/和平”。
- **出处**：Summit diplomacy 研究（具体版本待核）。

### 6. 翻译/口译 / interpreter（全球）【高】

- **做法**：同传/交传/笔记/耳机/隔间/保密/错误/危险；国家/公司/战争；谁翻译，谁有权力。
- **逻辑**：翻译=“桥/过滤器/秘密”；谁控制语言，谁控制谈判。
- **可借**：王都的“灰译/炉舌”；玩家可以译/错/被收买；翻译是“语言/权力/秘密”。

## 七、怎么用

1. **先看具体案例**：不要写“国际社会……”，写“联合国/美苏/日内瓦/卢旺达/罗兴亚……”。
2. **再看“谁在讲/谁受益”**：大国/小国/机构/公司/难民都在争解释权。
3. **借逻辑，不借表面**：安理会→灰席；蓝盔→炉卫；护照→炉牌；死信箱→炉藏；国宴→炉宴。
4. **标注可信度**：`【中】/【待核】` 的条目，写进游戏前再查。
5. **不要猎奇**：战争/间谍/难民/制裁，背后是真实的人；写制度，不写“奇观”。
