# 现实风俗素材库·二十五：中亚、高加索、西伯利亚、加勒比、拉美、太平洋

> 状态：素材收集 v0.1，2026-11-26。
>
> 用途：补前二十卷没深挖的地区，每条给“具体地区/民族 + 做法 + 逻辑 + 可借 + 出处”。
>
> 说明：
> - 这些地区不是“一个文化”；每条都尽量标具体民族/国家。
> - 出处以民族志/历史研究/博物馆/UNESCO 为主；百科只当入口。
> - `【高】` = 学术/博物馆/UNESCO 来源较可靠；`【中】` = 来源较泛/地区差异大，写进游戏前再核；`【待核】` = 只当线索。
> - 涉及殖民/种族/战争/原住民的内容，写作时不要猎奇；借制度逻辑，不借“异域奇观”。

## 一、中亚

### 1. 玛纳斯史诗 / Manas（吉尔吉斯斯坦）【高】

- **做法**：吉尔吉斯口头史诗，讲英雄玛纳斯/后代/战争/联盟；由 manaschi（史诗演唱者）演唱，可用手势/节奏/出神；长度数万行。
- **逻辑**：历史/谱系/身份在“唱”里；谁记得/唱得好，谁有权威。
- **可借**：坑沿镇的“灰玛纳斯/炉歌”；玩家可以听/学/被史诗带走；史诗是“历史/身份/记忆”。
- **出处**：Manas 研究（如 *The Manas Epic* 相关论著；具体版本待核）。

### 2. 马哈拉 / mahalla（乌兹别克斯坦）【高】

- **做法**：城市/村庄的邻里社区（mahalla），有长老/委员会/节日/互助/纠纷调解；国家/宗教/社区。
- **逻辑**：邻里是“小国家/大家庭”；谁在 mahalla 有威望，谁有权力。
- **可借**：坑沿镇的“灰马哈拉/炉巷”；玩家可以住/被调解/被排挤；邻里是“社区/规矩/互助”。
- **出处**：Mahalla 研究（具体版本待核）。

### 3. 帕米尔房屋 / Pamiri house（塔吉克斯坦）【中】

- **做法**：查莫罗人用石柱/石帽（latte）做房屋基座/支撑；支柱/石帽/排列；祖先/身份/建筑；考古/旅游。
- **逻辑**：石头=“家/身份/记忆”；谁建/谁住，代表家族/权力。
- **可借**：王都的“灰拉提/炉柱”；玩家可以看/偷/被咒；石柱是“家/身份/记忆”。
- **出处**：Latte stones 研究（具体版本待核）。

## 七、怎么用

1. **先看具体地区/民族**：不要写“中亚人/加勒比人……”，写“吉尔吉斯/乌兹别克/格鲁吉亚/萨哈/海地/牙买加/汤加……”。
2. **再看“谁在讲/谁受益”**：殖民/苏联/国家/旅游/资本都在改写这些风俗。
3. **借逻辑，不借表面**：supra→灰宴；khachkar→灰碑；Ysyakh→炉节；Vodou→炉神；tango→炉舞。
4. **标注可信度**：`【中】/【待核】` 的条目，写进游戏前再查。
5. **不要猎奇**：殖民/种族/战争/原住民，背后是真实的人；写制度，不写“异域奇观”。
