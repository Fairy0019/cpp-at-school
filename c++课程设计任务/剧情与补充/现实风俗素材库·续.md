# 现实风俗素材库·续

> 状态：素材收集 v0.1，2026-11-26。
>
> 用途：继续为《沉没王都》收集现实风俗。与第一卷不重复；第一卷已有的（约鲁巴双胞胎、翻骨节、ma'nene、冥途路引、努尔幽灵婚姻、面朝下埋葬、戒名、xenia、potlatch、kula 等）这里不再展开。
>
> 标记：`【高】` = 常见民族志/历史记载，较可靠；`【中】` = 地区性较强或细节有差异，写进游戏前再核；`【待核】` = 我把握不大，只当线索。
>
> 原则：借“当地人为什么觉得合理”，不照搬表面；涉及丧葬、宗教、身体改造的内容，换语境、改表面，避免直接消费。

## 一、出生、童年与成年

### 1. 抓周 / 돌잡이（中国、韩国）【高】

- **做法**：孩子满周岁时，桌上摆书、笔、算盘、钱、食物、玩具等；孩子先抓什么，就被解释成将来会做什么。
- **逻辑**：孩子不会说话，但“选择”被视为命运/性格的预兆；大人把随机的一抓解释成一个故事。
- **可借**：一个仪式，把孩子的未来交给一次随机选择；大人再把这个选择讲成“命中注定”。可以做成主角/孤儿帮的“命名日”变体。

### 2. 七五三（日本）【高】

- **做法**：男孩女孩在 3 岁、5 岁、7 岁（奇数年龄）去神社参拜，穿正式服装，拍纪念照；奇数被视为吉利。
- **逻辑**：孩子活到这些年龄，才算“站住了”；这是把“活下来”公开给社区看。
- **可借**：一个“活下来才算人”的年龄关卡；没过关的孩子没有正式名字/墓碑。

### 3. 剃胎毛（中国、日本等）【高】

- **做法**：婴儿第一次理发是一个小仪式；胎毛被保留下来，做成毛笔、饰品或护身物。
- **逻辑**：胎毛来自“还没成为社会人”的阶段；剪掉它，孩子才进入正式的名字/身份。毛发被保留，因为它仍然是“身体的一部分”。
- **可借**：身体残片作为身份凭证/护身物；主角的头发/指甲可能被旧机器读取。

### 4. 乳牙扔屋顶（中国、韩国、日本等）【高】

- **做法**：孩子掉牙后，把上牙扔到屋顶/床下，或交给老鼠，念一句“给你一颗旧牙，还我一颗新牙”。
- **逻辑**：牙齿是身体的一部分，不能随便丢；把它交给屋顶/老鼠，是让“新牙”知道该往哪里长。
- **可借**：身体残片与动物/房子的交换；一个很小的日常仪式，能暗示“身体不是封闭的”。

### 5. 胎盘埋葬（日本、中国、夏威夷、毛利等）【中】

- **做法**：把胎盘埋在家宅下、树下或特定地点；有的地方认为胎盘是孩子的“另一个身体”，埋在哪里决定孩子属于哪里。
- **逻辑**：出生不是孩子一个人的事，是把孩子“固定”到一个地方/家族；胎盘是人与土地的第一份契约。
- **可借**：主角的“出生地”可能是一间房/一棵树/一块炉渣；找到胎盘埋在哪里，就找到他属于谁。

### 6. 乳亲 / milk kinship（伊斯兰世界、地中海等）【高】

- **做法**：一个孩子如果吃过另一位女性的奶，就和她的孩子成为“乳兄弟姐妹”；这种关系可能带来婚姻禁忌和亲属义务。
- **逻辑**： kinship 不只看血，也看“共同吃过的东西”；奶是身体的一部分，能把两个家庭连起来。
- **可借**：核心/炉心可以制造“乳亲”：喝过同一炉水/同一批药的人，被制度当成亲属。

### 7. 教父母 / compadrazgo（伊比利亚、拉美、菲律宾等）【高】

- **做法**：孩子受洗时，父母请一对教父母（padrinos）；教父母对孩子有道德/经济责任，两个家庭成为“compadres”，关系可以延续几代。
- **逻辑**：孩子不只有一对父母；教父母是“社会性的第二父母”，用来扩展保护网。
- **可借**：主角在城门/营地被某个人“认领”，获得一个第二身份；这个身份可能比血缘更管用。

### 8. 干亲（中国）【高】

- **做法**：孩子体弱/八字不好时，父母让孩子认另一对夫妻为“干爹干妈”，改口、送礼、逢年过节走动；有时也认树、石头、菩萨为干亲。
- **逻辑**：孩子的“命”太弱，需要借别人的福气/名字来保护；干亲是一种社会性的“补命”。
- **可借**：主角的临时身份牌可以认一个“干名字”；这个名字在系统里不存在，但在人那里有效。

### 9. 结拜 / 血盟（多地）【高】

- **做法**：没有血缘的人通过仪式（喝血酒、交换信物、拜天地）结为兄弟/姐妹；彼此承担家庭义务，甚至继承对方的名字/债务。
- **逻辑**： kinship 可以被“做”出来；誓言比血更重，因为它是自己选的。
- **可借**：玩家可以和 NPC 结拜，获得“家人”身份；但结拜也意味着继承对方的债/仇。

### 10. 成年礼 / initiation（多地）【高】

- **做法**：青少年经过隔离、考试、疼痛、禁食、换名、换衣、纹身/疤痕等仪式，进入成年；仪式前后是两个不同的人。
- **逻辑**：成年不是自然发生的，是被共同体承认的；身体/名字要留下记号，证明你通过了。
- **可借**：主角的“醒来”可以是一场成年礼；他通过核心的测试，才获得“维护者”的名字。

### 11. 阿布库 / abiku（约鲁巴）【中】

- **做法**：如果一个孩子反复夭折，家人可能认为他是“abiku”——一个在生死之间来回的孩子；会给他取特别的名字、做记号、举行仪式，让他留下来。
- **逻辑**：死亡不是一次性的；同一个孩子可能回来多次。名字/记号是“留住他”的绳子。
- **可借**：一个反复死而复生的角色；名字是把他绑在活人世界的绳子。

## 二、求偶、婚姻与性别

### 12. 表亲婚 / cross-cousin marriage（印度、中东、澳大利亚等）【高】

- **做法**：优先和特定类型的表亲结婚（如母亲的兄弟的女儿、父亲的姐妹的女儿）；在某些社会，这是“最合适”的婚姻。
- **逻辑**：婚姻是家族联盟；表亲婚把财产/关系留在同一个网络里。对外人来说像乱伦，对内部人来说是“亲上加亲”。
- **可借**：旧国的贵族可能鼓励“表亲婚”，把签名/权限留在家族内；主角作为外来者，打破了这个循环。

### 13. 试婚 / bundling（早期近代欧洲、北美）【中】

- **做法**：求偶中的年轻男女可以同床过夜，但穿着衣服/隔着床板；这是测试兼容性/体温的方式，不是性许可。
- **逻辑**：婚姻是长期合作，需要“试”；但试的边界由社区规定。亲密可以被制度允许，也可以被制度限制。
- **可借**：一种“有限亲密”的习俗；两个人可以共享一个空间，但不能越过某条线。

### 14. 冥婚 / posthumous marriage（中国、法国等）【高】

- **做法**：死者可以与死者/活人结婚；中国有冥婚，法国有经总统许可的“死后婚姻”。目的是给死者一个名分/伴侣/后代。
- **逻辑**：婚姻不是只有活人的事；死者也需要社会身份。活人可以通过婚姻改变死者的地位。
- **可借**：旧王死后被“配”给一个名字/家族；主角是这个死后婚姻的产物/继承人。

### 15. 女人娶妻 / woman-woman marriage（努尔、达荷美、伊博等）【中】

- **做法**：一个没有孩子的女人可以用牛/财产“娶”另一个女人；后者与男性生育的孩子，法律上属于“女丈夫”和她的家族。
- **逻辑**：婚姻的核心是 lineage/财产，不是性；性别角色可以被制度重新分配。
- **可借**：一个女性角色以“丈夫”身份继承家族；主角的“父亲”可能是一个社会角色，不是生物角色。

### 16. 宣誓处女 / sworn virgins（巴尔干）【中】

- **做法**：一些女性发誓终身不婚、像男人一样生活，获得男性的社会/法律地位；她们可以继承财产、带枪、当家长。
- **逻辑**：在没有男性继承人的家庭里，女性可以通过“放弃女性身份”来保住家族；性别是法律/社会角色。
- **可借**：一个角色通过“放弃某种身份”获得另一种权力；主角也可以选择“不做旧王的继承人”，而做别的东西。

### 17. 巴赫波什 / bacha posh（阿富汗）【中】

- **做法**：一些家庭把女儿打扮成男孩，直到青春期；她可以上学、工作、陪姐妹出门，获得男孩的自由。
- **逻辑**：性别是一种“通行证”；在限制女性行动的社会里，假装男孩是家庭策略。
- **可借**：一个角色靠“冒充另一个性别/身份”获得行动自由；身份牌上的性别可以是假的。

### 18. 双灵 / two-spirit（北美原住民多民族）【中】

- **做法**：许多北美原住民族有第三性别/第四性别的社会角色，现代统称“two-spirit”；这些人承担仪式、医疗、调解等特殊职能。
- **逻辑**：性别不是二元；某些人同时拥有男/女的精神特质，因而有特殊的社会位置。
- **可借**：你的世界可以有“同时属于两边”的人；他们能读两种文字/进两个空间。

### 19. 海吉拉 / hijra（南亚）【中】

- **做法**：海吉拉是一个第三性别/跨性别社群，传统上在婚礼、出生仪式上唱歌祝福，也在某些政治/宗教场合有角色。
- **逻辑**：性别/身份不是只有男女；海吉拉被社会分配了一个“介于之间”的位置，既有力量也被排斥。
- **可借**：一个“介于生死/男女/国族之间”的群体，能替人祝福/诅咒，也能替人传递消息。

### 20. 婚姻占星 / horoscope matching（印度等）【高】

- **做法**：结婚前，双方家庭请占星师看星盘；如果星盘不合，婚事可能告吹。
- **逻辑**：婚姻不只是两个人的事，也是宇宙秩序的事；星星比人更有发言权。
- **可借**：旧国的“签名/炉心”可以代替星盘；核心读出的签名决定谁有资格结婚/继承。

### 21. 走婚 / 摩梭（中国云南）【中】

- **做法**：摩梭人传统上实行“走婚”：男女晚上相会，白天各回自己母亲家；孩子由母亲家族抚养，父亲不组成独立家庭。
- **逻辑**：婚姻不是“搬到一起”，而是“互相走访”；家庭的核心是母系，不是夫妻。
- **可借**：一种“不组成家庭”的亲密关系；主角可以有一个“晚上的家”和一个“白天的家”。

### 22. 一妻多夫 / fraternal polyandry（西藏、喜马拉雅）【中】

- **做法**：几个兄弟共同娶一个妻子，财产/土地不分家；孩子属于整个兄弟群体。
- **逻辑**：在土地稀缺的地方，分家会毁掉家业；共妻是保住财产的方式。
- **可借**：一个“共享配偶/共享继承人”的制度；主角可能是几个“父亲”共同的孩子。

### 23. 交换婚 / sister exchange（多地）【中】

- **做法**：两个家庭互相交换女儿为妻，不用聘礼/嫁妆；如果一方违约，另一方也要退婚。
- **逻辑**：婚姻是双向的契约；没有钱，就用“人”来平衡。
- **可借**：两个家族交换“人质/新娘”；主角的身份可能是一笔交换的抵押。

### 24. 嫁树 / marrying a tree（印度等）【中】

- **做法**：如果一个人的星盘/命相不吉，可以先和一棵树/一尊神像结婚，把“厄运”转移出去，再和真人结婚。
- **逻辑**：婚姻是一种技术，可以用来处理厄运；第一次婚姻是“假的”，但它有真实的仪式效力。
- **可借**：主角可以先和炉心/旧王的签名“结婚”，再决定要不要和活人建立关系。

## 三、家庭、亲属与继承

### 25. 舅权 / avunculate（多地）【高】

- **做法**：在母系/双系社会中，母亲的兄弟（舅舅）对孩子有比父亲更大的权威；舅舅负责管教、嫁娶、继承。
- **逻辑**：父亲是“外人”，舅舅才是“自己家族的男人”；亲属关系不是按父系一条线算的。
- **可借**：主角的“父亲”缺席，但有一个舅舅式的角色（四骑士/商人/老工匠）承担父职。

### 26. 产翁 / couvade（南美、亚洲、欧洲民间）【中】

- **做法**：妻子生孩子后，丈夫躺在床上“坐月子”，遵守饮食/行为禁忌，接受亲友探望；真正生产的妻子可能马上下地干活。
- **逻辑**：父亲的身份不是生物性的，而是社会性的；他也要通过“受苦”来获得父亲身份。
- **可借**：一个“谁生孩子”的仪式；主角的“出生”可能由旧王/机器来“坐月子”。

### 27. 多父 / partible paternity（南美一些社会）【中】

- **做法**：一个孩子可以有多个“父亲”；母亲的所有性伴侣都可能被认定为父亲，各自对孩子有责任。
- **逻辑**：孩子是多个男人的共同作品；父亲是社会责任，不是唯一的生物来源。
- **可借**：主角可能有多个“造物主”：旧王、工匠、议会、炉心；每个都只承担一部分父职。

### 28. 幼子继承 / ultimogeniture（蒙古、欧洲部分地区等）【中】

- **做法**：最小的儿子继承家宅/土地，年长的儿子外出另立门户；因为幼子一直和父母住，负责养老/祭祀。
- **逻辑**：继承不是“长子优先”，而是“谁留下照顾家，谁继承家”。
- **可借**：旧王的“继承者”不是最早造的，而是最后留下看火的那个；第一个造物被派出去，主角留下。

### 29. 长子继承 / primogeniture（欧洲、日本等）【高】

- **做法**：长子继承全部/大部分家产，次子/幼子外出当兵、当教士、做学徒。
- **逻辑**：家产不分，家族才不会衰落；非长子成为“多余的人”，推动扩张/战争/殖民。
- **可借**：旧国的贵族把非长子送去当兵/守炉；四骑士可能是“没有继承权的孩子”。

### 30. 寄养 / fosterage（西非、欧洲贵族、太平洋等）【中】

- **做法**：孩子被送到亲戚/盟友/老师家里长大，不跟亲生父母住；寄养家庭负责教育/联姻。
- **逻辑**：孩子是建立联盟的纽带；家庭不是一座房子，而是一张网。
- **可借**：主角从小被寄养在城门/营地/商人家里；他的“家”不是一个地方，而是一串关系。

### 31. 玩笑关系 / joking relationship（非洲多地）【高】

- **做法**：某些亲属（如表亲、祖孙、姻亲）之间被允许/要求互相取笑、辱骂、抢东西，而不能生气。
- **逻辑**：用玩笑释放紧张；越是亲密/潜在冲突的关系，越需要制度化的玩笑。
- **可借**：某些 NPC 只能用玩笑/辱骂表达关心；玩家如果当真，会破坏关系。

### 32. 回避关系 / avoidance（多地）【高】

- **做法**：某些亲属（如女婿与岳母、儿媳与公公）必须避免单独相处/直接说话/身体接触；违反会被视为乱伦/不敬。
- **逻辑**：用距离维持秩序；亲近的人反而需要最严格的边界。
- **可借**：某些名字/面具不能同时出现；玩家必须在门口/帘子/第三人传话。

### 33. 祖先牌位（中国等）【高】

- **做法**：死者的名字写在牌位上，放在家中/祠堂；家人定期上香、供饭。没有牌位/名字的死者可能变成孤魂/饿鬼。
- **逻辑**：死者需要一个人间的“地址”才能被祭祀；名字是他们在另一个世界的身份证。
- **可借**：核心/城门机器只认“牌位/签名”，不认尸体；主角的身份牌就是一块移动的牌位。

### 34. 过继 / posthumous adoption（中国、日本等）【高】

- **做法**：没有儿子的死者，可以从亲戚/同族中过继一个儿子，继承名字/财产/祭祀；有时在死后才办。
- **逻辑**： lineage 比血缘重要；死者需要一个“名义上的后代”来继续香火。
- **可借**：旧王无嗣，主角被“过继”给旧王的名字；不是亲生，是制度性的儿子。

### 35. 母系继承 / matriliny（米南加保、霍皮、易洛魁等）【高】

- **做法**：财产/姓名/身份通过母亲传给女儿；舅舅负责管教姐妹的孩子；父亲在自己的母系家族里是舅舅。
- **逻辑**：家族的核心是母系；男人不把财产传给自己的孩子，而是传给姐妹的孩子。
- **可借**：旧国的“王”不是世袭，但“炉心/签名”可能通过母系/师徒传递；主角的继承权来自母亲/工匠，不是父亲。

## 四、死亡、哀悼与祖先

### 36. 悬棺（中国、菲律宾、印尼）【高】

- **做法**：棺材被放在悬崖洞穴/木桩上，不埋入土；越高越接近天/祖先。
- **逻辑**：死者不应该和活人抢地；高处是“另一个世界”的入口。棺材悬空，也防止被破坏/被动物挖。
- **可借**：王都的死者被放在高处/塔顶；玩家要爬上去才能读到名字。

### 37. 树葬（西藏、印尼、菲律宾等）【中】

- **做法**：尸体被放在树上/树洞里，让身体回归自然；有的地方认为树是死者的家。
- **逻辑**：身体来自自然，应该回到自然；树是连接生死的媒介。
- **可借**：王都的“树”可能是炉心/管道；死者的名字刻在树皮上，树活着，死者就还在。

### 38. 尸骨屋 / ossuary（欧洲、中东等）【高】

- **做法**：尸体先埋葬，等肉腐烂后，骨头被取出、清洗、堆放在尸骨屋/地下墓穴；头骨可能被排列/展示。
- **逻辑**：土地有限，骨头需要“二次安置”；死亡是分阶段的，骨头是死者的最终形态。
- **可借**：王都的地下有一间“骨屋”，所有死者的名字/头骨按家族排列；玩家要找的那个名字在某一排。

### 39. 死亡面具（罗马、欧洲、非洲等）【高】

- **做法**：人死后，用蜡/石膏/金属拓下脸，做成面具；面具被保存在家里/祠堂，供后人祭拜。
- **逻辑**：脸是身份的一部分；身体腐烂后，面具代替脸继续存在。
- **可借**：核心/城门用“死亡面具”识别死者；主角的面具可能是从死人脸上拓下来的。

### 40. 遗像 / post-mortem photography（维多利亚时代等）【高】

- **做法**：人死后，摄影师给尸体拍照，摆成坐姿/站姿，甚至画上睁开的眼睛；照片成为家人最后的纪念。
- **逻辑**：照片是“最后的脸”；死者看起来还活着，家属才能接受。
- **可借**：王都的“遗像”会动/说话；玩家分不清照片里的人是死是活。

### 41. 哀悼珠宝 / mourning jewelry（维多利亚时代）【高】

- **做法**：用死者的头发编成手链/胸针/戒指，戴在身上；珠宝上刻名字/日期。
- **逻辑**：身体的一部分可以随身携带；哀悼不是“放下”，而是“带着走”。
- **可借**：主角戴着母亲/旧王的头发/骨片；这件珠宝是进入某个地方的钥匙。

### 42. 职业哭丧 / professional mourners（中国、地中海、中东等）【高】

- **做法**：葬礼上请专业的哭丧人/哀歌队，替家属哭、唱、念；哭得越响，葬礼越体面。
- **逻辑**：哀悼是一种公共表演/劳动；家属可能哭不出来，但社会需要“哭声”。
- **可借**：一个靠“替人哭”为生的 NPC；玩家可以雇她哭一个没有人为他哭的死者。

### 43. 守夜 / wake（爱尔兰、加勒比等）【高】

- **做法**：死者停灵期间，亲友通宵守夜，喝酒、讲故事、唱歌、甚至玩游戏；葬礼既是哀悼，也是聚会。
- **逻辑**：死亡是社区事件；用热闹送走死者，比用沉默更尊重他。
- **可借**：营地/酒馆的“守夜”场景；玩家可以在葬礼上听到死者生前的秘密。

### 44. 爵士葬礼 / jazz funeral（新奥尔良）【高】

- **做法**：葬礼队伍有铜管乐队，先奏哀乐，下葬后奏欢快的爵士乐；送葬者跟着音乐跳舞。
- **逻辑**：死亡是“回家”，应该用音乐送行；哀悼和庆祝可以同时发生。
- **可借**：王都的葬礼/出城仪式用音乐标记；玩家可以通过曲子判断死者是谁。

### 45. 幻想棺材 / fantasy coffins（加纳）【高】

- **做法**：棺材被做成死者生前的职业/爱好/身份的形状：鱼、汽车、飞机、可可荚、书、狮子等。
- **逻辑**：棺材是死者的“最后一件衣服/身份”；你活着是什么，死了就坐什么走。
- **可借**：每个角色的棺材形状暗示他的秘密身份；玩家可以通过棺材反推死者。

### 46. 食罪人 / sin-eater（英国、威尔士民间）【中】

- **做法**：死者家里请一个穷人，把面包/啤酒放在尸体上，然后让食罪人吃掉；他替死者承担未忏悔的罪。
- **逻辑**：罪是一种“债”，可以由别人吃掉/接走；食罪人拿钱，但社会地位很低。
- **可借**：一个替死者吃罪的职业；主角可以替旧王吃罪，也可以拒绝。

### 47. 扫墓 / 清明（中国）【高】

- **做法**：每年清明，家人去墓地除草、培土、摆供、烧纸、说话；墓地需要定期维护。
- **逻辑**：死者的“家”也需要修缮；没人扫墓的死者会变成孤魂。
- **可借**：王都的墓/碑需要玩家维护；长期不扫墓，死者的名字会消失。

### 48. 饥饿鬼 / hungry ghost（中国等）【高】

- **做法**：没有后代/名字/供品的死者会变成饿鬼，在人间游荡；中元节会普度/施食。
- **逻辑**：死亡不是终点，遗忘才是；没有名字/供品的死者会“饿”。
- **可借**：王都里最危险的死灵不是最凶的，而是被遗忘的；玩家可以给他们名字/食物。

## 五、食物、宴席与禁忌

### 49. 洁食 / kosher & halal（犹太教、伊斯兰教）【高】

- **做法**：规定可吃什么、不可吃什么、怎么屠宰、肉奶能不能同食；违反就是污染。
- **逻辑**：饮食是身份边界；和谁吃、吃什么，决定你属于哪个共同体。
- **可借**：旧国/新国/当下各有“能吃/不能吃”的规则；主角吃错东西会被识破身份。

### 50. 斋戒 / fasting（ Ramadan、四旬斋、赎罪日等）【高】

- **做法**：在特定时间禁食/禁欲/禁言；日落之后才能吃。
- **逻辑**：身体是被训练的；饿/渴让人记住共同体/神/死者。
- **可借**：王都的“炉静夜”要求全镇禁食/禁声；违反的人会被死者听见。

### 51. 咖啡仪式（埃塞俄比亚）【高】

- **做法**：咖啡豆现场烘烤、研磨、煮三轮；客人围坐，边喝边聊，持续几个小时。
- **逻辑**：咖啡不是饮料，是待客/谈判/社区的时间；喝几轮、谁先喝，都有规矩。
- **可借**：酒馆的“三轮茶/咖啡”仪式；玩家必须在第几轮提出请求。

### 52. 卡瓦 / kava（太平洋岛屿）【高】

- **做法**：用卡瓦根磨粉、加水，在仪式中依次敬给客人；喝完后舌头麻木、放松。
- **逻辑**：共饮卡瓦是结盟/和解/欢迎；谁先喝、谁喝哪一碗，代表身份。
- **可借**：一种“喝了就不能说谎/动手”的饮料；玩家可以选择喝/不喝。

### 53. 槟榔 / betel nut（南亚、东南亚、太平洋）【高】

- **做法**：槟榔果配石灰/蒌叶，嚼出红色汁液；待客、提亲、谈判都先递槟榔。
- **逻辑**：槟榔是“开口”的礼物；接受槟榔等于接受关系。红嘴是身份/美的标志。
- **可借**：一种红色的待客植物；玩家接受/拒绝会改变 NPC 态度。

### 54. 圣餐 / communion（基督教）【高】

- **做法**：面包/葡萄酒在仪式中被祝圣，信徒吃掉，象征基督的身体/血。
- **逻辑**：吃下神，神就住在你里面；共同体通过“吃同一个身体”结合。
- **可借**：炉心的“核心”被分食/饮用；吃下它的人获得记忆/权限，也承担诅咒。

### 55. 初穗 / first fruits（多地）【高】

- **做法**：第一批收获的谷物/水果先献给神/祖先/国王，然后人才吃。
- **逻辑**：第一口不属于人，属于给生命的那一方；先给，才有资格吃。
- **可借**：王都的第一炉铁/第一块矿石先献给炉心；私吞第一口的人会招灾。

### 56. 图腾禁忌 / totem taboo（多地）【高】

- **做法**：每个氏族有一种图腾动物/植物，通常禁止猎杀/食用；图腾是祖先/保护者。
- **逻辑**：你和你吃的东西有亲属关系；吃图腾等于吃祖先。
- **可借**：每个家族有一种“不能碰”的怪物/矿石；主角的家族禁忌可能是解开核心的钥匙。

### 57. 共餐 / commensality（多地）【高】

- **做法**：谁和谁同桌、谁先动筷、谁吃哪一部分，都有规矩；共餐表示接纳/结盟。
- **逻辑**：吃在一起，就是一家人；把外人纳入共餐，是最强的接纳信号。
- **可借**：营地/酒馆的“共餐”事件；玩家可以选择和谁吃，改变阵营。

### 58. 左手禁忌（南亚、中东、非洲等）【高】

- **做法**：左手被视为不洁，用于清洗/如厕；吃饭、递东西、握手必须用右手。
- **逻辑**：身体被分成“干净/不洁”两部分；用错手是失礼/污染。
- **可借**：王都的“右手/左手”规矩；主角用错手会暴露外来者身份。

### 59. 面包与盐（斯拉夫、东欧等）【高】

- **做法**：迎接贵客时，献上面包和盐；客人掰一块面包蘸盐吃。
- **逻辑**：面包是生命，盐是纯洁/契约；一起吃了，就是朋友。
- **可借**：城门/营地的欢迎仪式；接受面包和盐，等于接受主人的保护/约束。

## 六、服饰、身体与美

### 60. 面纱 / veiling（伊斯兰世界、地中海、南亚等）【高】

- **做法**：女性/男性用布遮住头发/脸/身体；不同地区遮的部位不同，含义也不同。
- **逻辑**：遮蔽是保护/身份/阶级/宗教；谁可以看谁，是权力。
- **可借**：王都的“面具/面纱”制度；遮得越多，身份越高/越危险。

### 61. 头巾 / turban（锡克教、中东、南亚等）【高】

- **做法**：男性/女性缠头巾，颜色/样式代表身份/宗教/家族；摘头巾是极大的羞辱。
- **逻辑**：头是神圣的；头巾是“戴在头上的名字”。
- **可借**：不同阵营的头巾颜色；玩家可以通过头巾认人，也可能认错。

### 62. 疤痕 / scarification（非洲、澳洲、太平洋等）【高】

- **做法**：用刀/火在皮肤上留下疤痕，作为成年/身份/美的标志；疤痕的形状代表家族/阶层。
- **逻辑**：身体是一份文件；疤痕是永久的签名，不能伪造/脱下。
- **可借**：王都的“身份牌”之外，还有“身体上的签名”；主角的身体可能有旧王的记号。

### 63. 纹身 / tattoo（波利尼西亚、毛利、日本等）【高】

- **做法**：用针刺入颜料，在皮肤上留下永久图案；图案代表家族/ rank/ 经历/保护。
- **逻辑**：身体是族谱/地图；纹身是“穿在身上的历史”。
- **可借**：主角的纹身是一张地图/一段旧王日志；不同阵营能读不同的部分。

### 64. 黑齿 / teeth blackening（日本、东南亚等）【高】

- **做法**：用铁浆/植物汁把牙齿染黑，作为美/成年/已婚的标志。
- **逻辑**：白牙被视为野兽/不洁；黑齿才是“人”的美。
- **可借**：王都的“黑齿”是贵族/已婚的标志；玩家可以通过牙齿判断身份。

### 65. 颈环 / neck rings（缅甸 Kayan 等）【中】

- **做法**：女性从小戴铜环，逐渐增加，拉长脖子；被视为美/身份。
- **逻辑**：身体可以被改造为“族群的美”；但这也是旅游/剥削的焦点。
- **可借**：王都的贵族用金属环/面具改变身体；主角要判断这是美还是刑具。

### 66. 唇盘 / lip plate（埃塞俄比亚 Mursi 等）【中】

- **做法**：女性在下唇穿洞，放入陶盘/木盘，逐渐扩大；盘子越大，美/身份越高。
- **逻辑**：身体改造是成年/婚姻/族群的标志；外人常把它当猎奇。
- **可借**：王都的“面具”可能是嵌在脸上的；摘不下来，也不应该摘。

### 67. 缠足 / foot binding（中国）【高】

- **做法**：女孩小时候把脚骨折断、裹紧，使脚停止生长，形成“三寸金莲”；被视为美/身份。
- **逻辑**：美可以是暴力；女性的行动被限制，也被当成家族荣誉。
- **可借**：王都的“美”可能是一种刑具；贵族女性的面具/鞋子让她们走不快。

### 68. 哀悼服 / mourning dress（多地）【高】

- **做法**：丧期穿特定颜色/材质（黑/白/麻），时间长短代表关系亲疏；丧期结束换回常服。
- **逻辑**：衣服是时间/身份的标记；别人看到你的衣服，就知道你还在丧期。
- **可借**：王都的“丧期颜色”制度；玩家可以通过衣服判断谁死了/谁在撒谎。

### 69. 头发 / hair（多地）【高】

- **做法**：头发可以代表灵魂/荣誉/哀悼/身份：锡克教不剪发，寡妇剪发/披发，死者头发被保留，第一次剃头是仪式。
- **逻辑**：头发是身体的一部分，也是可以“展示/切割”的身份。
- **可借**：主角的头发/旧王的头发是钥匙；剪发/剃头是剥夺身份。

### 70. 胡须 / beard（阿米什、锡克教、东正教等）【高】

- **做法**：男性留胡须/剃胡须，代表宗教/身份/成年/职业；强制剃须是羞辱。
- **逻辑**：脸是公共的；胡须是“长在脸上的旗帜”。
- **可借**：不同阵营的胡须样式；主角剃/留胡须改变 NPC 反应。

## 七、房屋、空间与城市

### 71. 四合院 / courtyard house（中国、中东、罗马等）【高】

- **做法**：房子围着一个院子，外墙高、窗户少；家庭生活朝向内部，外部是墙/门。
- **逻辑**：家是“内部世界”；院子是私密/安全/家族的核心，街道是外人。
- **可借**：王都的“院”是家族/炉心的缩影；玩家从院子进入，才发现里面还有一层。

### 72. 吊脚楼 / stilt house（东南亚、中国南方等）【高】

- **做法**：房子架在木桩上，离地/离水；下面养牲畜/储物，上面住人。
- **逻辑**：地面是水/虫/敌人，高处才是家；房子是“浮起来的”。
- **可借**：坑沿镇的房子架在坑上；玩家走在木板上，下面就是深渊。

### 73. 蒙古包 / yurt（蒙古、中亚）【高】

- **做法**：圆形、可拆卸的帐篷，用木架/毛毡搭成；门朝南，内部有严格的空间/座位秩序。
- **逻辑**：家可以移动；空间秩序跟着人走。进门/坐哪边都有规矩。
- **可借**：游牧/拾荒者的帐篷城市；玩家进入不同帐篷要遵守不同的方位规矩。

### 74. 冰屋 / igloo（因纽特）【高】

- **做法**：用雪块砌成圆顶屋，只留一个低矮入口；内部靠体温/油灯取暖。
- **逻辑**：家是用环境本身做的；雪是材料，也是保温层。低入口防止热气逃逸。
- **可借**：王都的“雪层/灰层”房子；玩家要钻过低矮入口才能进入。

### 75. 塔楼 / tower houses（也门、意大利 San Gimignano 等）【高】

- **做法**：家族竞相建高塔，塔越高，家族越有面子/越安全；塔是防御/地位。
- **逻辑**：高度就是权力；从塔上可以看见别人，别人看不见你。
- **可借**：坑沿镇的高塔/城门塔；谁住得高，谁掌握信息/水源。

### 76. 屋顶 / rooftop（地中海、中东、印度等）【中】

- **做法**：屋顶是日常生活的延伸：睡觉、吃饭、晒粮、社交；邻居的屋顶相连。
- **逻辑**：家不只在地面；屋顶是“半公共”的空间，谁在上面，谁就被看见。
- **可借**：王都的屋顶是走私/传话的路线；玩家可以在屋顶上偷听。

### 77. 闺阁 / zenana（南亚、中东等）【中】

- **做法**：女性居住在房子的特定区域（zenana/harem），男性/外人不能随意进入；女性也有自己的社交/权力网络。
- **逻辑**：空间划分性别/权力；被隔离不等于没有权力，内部有自己的秩序。
- **可借**：王都的“内院”只有特定人能进；玩家要通过女性/仆人网络获取消息。

### 78. 浴场 / hammam、onsen、sauna（多地）【高】

- **做法**：公共/半公共的洗浴空间，赤裸/半裸，社交/清洁/仪式；不同性别/阶层有不同时间/区域。
- **逻辑**：赤裸是信任/平等；浴场是消息/交易/放松的场所。
- **可借**：王都的“澡堂”是唯一摘面具的地方；玩家可以在那里看到谁身上有疤痕/纹身。

### 79. 市场 / bazaar（多地）【高】

- **做法**：市场不只是买卖，也是社交/新闻/谈判/表演的场所；摊位按行业/家族排列，价格靠讨价还价。
- **逻辑**：市场是“公共客厅”；谁在哪个位置、谁和谁说话，都是信息。
- **可借**：坑沿镇的市场是主线/支线的集散地；玩家可以通过摊位位置判断势力。

### 80. 城门 / gate（多地）【高】

- **做法**：城门是进出城的唯一通道，检查身份/货物/税；城门也是告示/刑罚/示众的地方。
- **逻辑**：城门是“内外之间”的关卡；谁有资格进，谁被挡在外面，是权力。
- **可借**：你的游戏已经有城门/机械门卫；可以再加“城门下的告示/尸体/税收”。

### 81. 墓地 / graveyard in the center（多地）【高】

- **做法**：墓地/祠堂在村子/城市中心，而不是边缘；活人每天经过死者。
- **逻辑**：死者是社区的一部分；把他们放在边缘，等于忘记他们。
- **可借**：坑沿镇的中央是一个大墓/碑林；市场围着墓地建，孩子在墓碑间玩。

### 82. 城墙 / walled city（多地）【高】

- **做法**：城市被城墙包围，城门/塔楼/护城河；墙内是“我们”，墙外是“野蛮/荒野”。
- **逻辑**：墙是身份/安全/税收；墙越高，内外差别越大。
- **可借**：王都的“城墙”已经塌了一半；墙内/墙外的规矩不同。

## 八、劳动、交换与货币

### 83. 讨价还价 / bargaining（巴扎、市场等）【高】

- **做法**：价格不是固定的，买卖双方通过出价/还价/假装走人来谈判；最后成交价取决于关系/心情/信息。
- **逻辑**：价格是关系的产物，不是物体的属性；会砍价的人有面子。
- **可借**：商店/酒馆的讨价还价小游戏；玩家的名声/面具/身份影响底价。

### 84. 礼物经济 / gift economy（Mauss 等）【高】

- **做法**：礼物不是白给的；收礼的人欠人情，必须回礼；不回礼会丢面子/失去关系。
- **逻辑**：礼物是“绑人的绳子”；给得越多，欠得越多。
- **可借**：NPC 送礼/帮忙后，玩家欠下“人情债”；某些门只能用债/人情打开。

### 85. 债务奴役 / debt peonage（多地）【高】

- **做法**：欠债还不起的人，用劳动/身体/子女抵债；债务可以继承，雇主的商店/农场成了“债主的领地”。
- **逻辑**：债务不是数字，是人身控制；还不起债，就变成别人的财产。
- **可借**：坑沿镇的“深潜合同”就是债务；玩家签了合同，死了/残了都算自己的。

### 86. 贝币 / cowrie shells（非洲、亚洲、太平洋等）【高】

- **做法**：贝壳被当作货币/装饰/身份；贝壳的来源/大小/颜色决定价值。
- **逻辑**：货币不需要金属；稀缺/远方/美丽的东西都可以是钱。
- **可借**：王都的“矿石碎片”是硬通货；贝壳/骨头/牙齿也可以当钱。

### 87. 牛币 / cattle as money（东非、努尔等）【高】

- **做法**：牛是财富/聘礼/赔偿/地位；一个男人的牛群决定他能娶几个妻子、能赔多少命。
- **逻辑**：财富是活的；牛会繁殖/死亡/被偷，所以财富会呼吸。
- **可借**：王都的“炉兽/矿兽”是活的钱；玩家可以偷/养/杀。

### 88. 盐币 / salt as money（罗马、埃塞俄比亚等）【高】

- **做法**：盐块被当货币/工资；罗马士兵的“薪水”（salarium）与盐有关。
- **逻辑**：盐是生命必需品，又难保存/运输；谁控制盐，谁控制命。
- **可借**：王都的“盐”是净化/防腐/货币；盐矿是战略资源。

### 89. 符木 / tally sticks（中世纪欧洲等）【高】

- **做法**：在木棍上刻痕，一分为二，债主/债务人各持一半；还债时对合。
- **逻辑**：记录就是钱；木头上的刻痕比人的记忆可靠。
- **可借**：王都的“债务木/身份木”；玩家要找另一半才能证明自己是谁。

### 90. 纸币 / paper money（中国、世界）【高】

- **做法**：一张纸被国家/银行承诺可以换金属/货物；纸本身不值钱，值钱的是信任。
- **逻辑**：货币是集体相信的故事；国家倒了，纸就变成废纸。
- **可借**：新国的“公民币”已经变成废纸；老人还在用，年轻人只认矿石。

### 91. 剪币 / clipping coins（中世纪、罗马等）【高】

- **做法**：从金币/银币边缘剪下一点金属，再把硬币花出去；剪下的金属攒起来重铸。
- **逻辑**：货币的“面值”和“实际金属”分离；信任被一点点剪掉。
- **可借**：王都的硬币被剪/伪造；玩家可以通过重量/声音判断真假。

### 92. 行会 / guilds（中世纪欧洲、伊斯兰世界等）【高】

- **做法**：同一行业的工匠组成行会，控制价格/质量/学徒/准入；行会有自己的仪式/守护神/会馆。
- **逻辑**：行会是一个“职业家族”；没有行会，你不能在城里开店。
- **可借**：坑沿镇的拾荒者/矿工/商人有“行会”；玩家要入会才能接活。

### 93. 学徒 / apprenticeship（多地）【高】

- **做法**：孩子/少年被送到师傅家，住几年到十几年，学手艺；师傅管吃住/管教，学徒无偿劳动。
- **逻辑**：手艺是“父职”的替代；师徒关系比雇佣关系更亲/更严。
- **可借**：主角被一个老工匠“收养/收徒”；师傅知道旧王/炉心的秘密。

### 94. 公司镇 / company scrip（近代工业）【高】

- **做法**：矿场/工厂发行自己的货币/代金券，工人只能在公司商店花；工资/房租/食物都在公司内部循环。
- **逻辑**：雇主控制价格/生活/债务；工人永远逃不出公司镇。
- **可借**：矿区的“矿票”；玩家可以用矿票/金币/人情三种货币交易。

### 95. 互助会 / friendly societies（近代欧洲、华人社团等）【高】

- **做法**：工人/移民组成互助会，交会费，生病/死亡/失业时领救济；会馆/祠堂/义山是共同财产。
- **逻辑**：没有国家福利，就自己造一个“微型国家”；会员身份就是保险。
- **可借**：坑沿镇的“同乡会/孤儿帮”是互助会；玩家可以加入/背叛。

### 96. 典当 / pawn（多地）【高】

- **做法**：把物品/身份牌/武器押给当铺，借钱；还不上，物品归当铺。
- **逻辑**：急需现金时，物品是“临时卖了又买回”；当铺是穷人的银行。
- **可借**：玩家可以押身份牌/武器/记忆；还不上，身份就没了。

### 97. 彩票 / lottery（多地）【高】

- **做法**：卖号码/抽签，赢家拿走奖金；彩票也被用来筹款/赌博/占卜。
- **逻辑**：命运可以用钱买一次机会；穷人买希望，富人买名声。
- **可借**：酒馆的“炉心彩票”；中奖者可以获得一次进入核心的机会。

### 98. 拍卖 / auction（多地）【高】

- **做法**：物品/土地/奴隶/战利品公开叫价，价高者得；拍卖师控制节奏/气氛。
- **逻辑**：价格由竞争决定；拍卖是“公开的贪婪/表演”。
- **可借**：坑沿镇的“遗物拍卖”；玩家可以抬价/压价/识破假货。

## 九、法律、政治与权力

### 99. 神判 / trial by ordeal（中世纪欧洲、非洲等）【高】

- **做法**：让被告握热铁/走火/浸水/吞毒，根据伤口/沉浮判断有罪无罪；神会保护无辜者。
- **逻辑**：人无法判断真相，就交给神；身体是证据。
- **可借**：王都的“炉心审判”：把手伸进炉火/矿石，能活就是无罪。

### 100. 决斗 / trial by combat（中世纪欧洲）【高】

- **做法**：双方/代理人比武，赢者被视为神判胜者；决斗可以解决法律纠纷/荣誉纠纷。
- **逻辑**：武力是真相的证明；强者/被神眷顾者赢。
- **可借**：四骑士的“验证”可以是一场决斗；主角用战斗证明自己有资格。

### 101. 宣誓 / oath（多地）【高】

- **做法**：在神/祖先/国王/城门面前发誓；说谎会遭诅咒/失去身份。
- **逻辑**：誓言把话变成债；名字/身体/后代都可以做抵押。
- **可借**：主角在城门/核心发誓；违约会被机器/死者记录。

### 102. 替罪羊 / scapegoat（圣经、古希腊等）【高】

- **做法**：把社区的罪/污染转移到一只动物/一个人身上，然后赶走/杀死；社区因此净化。
- **逻辑**：罪是可以转移的；需要一个“外面的人”承担。
- **可借**：王都的“四灾”被嫁祸给四骑士/旧王；玩家可以揭穿/接受这个替罪羊。

### 103. 血仇 / feud（多地）【高】

- **做法**：一个家族杀了另一个家族的人，另一个家族必须复仇；复仇可以延续几代，直到赔偿/和解。
- **逻辑**： family 是法律单位；一个人的死，全家都有责任/权利。
- **可借**：坑沿镇的两个家族有血仇；玩家可以调解/利用/引爆。

### 104. 宣誓帮手 / compurgation（中世纪欧洲）【高】

- **做法**：被告找一群“宣誓帮手”证明自己的清白；他们不是证人，而是“人品担保人”。
- **逻辑**：真相不如社区信任重要；有人替你担保，你就无罪。
- **可借**：玩家要找 N 个 NPC 为自己担保；担保人可能被收买/威胁。

### 105. 避难所 / sanctuary（中世纪欧洲、古代）【高】

- **做法**：逃犯躲进教堂/神庙/特定区域，暂时不能被逮捕；一定时间后必须离开/受审。
- **逻辑**：神圣空间可以暂停世俗法律；门/门槛是边界。
- **可借**：城门/炉心/墓地是“避难所”；玩家可以躲进去，但会失去自由/时间。

### 106. 人质 / hostage（多地）【高】

- **做法**：战败方/盟友送出人质，保证条约/债务/和平；人质在对方宫廷长大，可能被同化/利用。
- **逻辑**：人是最可靠的抵押；人质的命/身份绑定条约。
- **可借**：主角/孤儿/贵族孩子被当人质；玩家可以选择救/利用/交换。

### 107. 赞助 / patronage（罗马、拉美、艺术史等）【高】

- **做法**：有钱/有权的人赞助艺术家/学者/穷人，后者为客户/门客，提供忠诚/服务/作品。
- **逻辑**：保护是交易；赞助人买名声/人才/选票，被赞助人卖自由/时间。
- **可借**：商人/贵族赞助主角下潜；玩家要还人情/作品/忠诚。

### 108. 户口 / census（罗马、中国等）【高】

- **做法**：国家定期登记人口/财产/职业/家庭，作为征税/征兵/分配的依据；没有登记就是“无籍”。
- **逻辑**：国家通过“名字/数字”控制人；没有户口，你不存在。
- **可借**：城门机器就是 census 的残骸；主角的临时牌是“临时户口”。

### 109. 路引 / passport（明代中国、近代欧洲等）【高】

- **做法**：跨城/过关需要官府发的通行证，写明姓名/籍贯/目的地/体貌；没有路引不能通行。
- **逻辑**：国家通过“纸”控制移动；路引是活人的“冥途路引”。
- **可借**：主角的身份牌就是路引；城门/关卡/核心都认这张纸。

### 110. 禁奢法 / sumptuary laws（古罗马、中世纪欧洲、中国等）【高】

- **做法**：法律规定不同阶级只能穿某色/某料/某款式；平民不能穿贵族颜色/皮毛/珠宝。
- **逻辑**：衣服是阶级的制服；穿错就是僭越/犯罪。
- **可借**：王都的面具/颜色/布料代表身份；玩家穿错会被抓/被识破。

### 111. 包税 / tax farming（罗马、奥斯曼、法国等）【高】

- **做法**：国家把某地区的收税权拍卖给私人/包税人；包税人先付一笔钱，然后自己向百姓收税，差额归自己。
- **逻辑**：国家要现金，包税人要利润；百姓被两边榨。
- **可借**：坑沿镇的“矿税”被包给商人；玩家可以替商人收税/替百姓抗税。

### 112. 徭役 / corvée（多地）【高】

- **做法**：国家/领主强制百姓每年无偿劳动若干天，修路/挖河/建城/运粮。
- **逻辑**：国家不只收钱，还收时间/身体；徭役是“隐形的税”。
- **可借**：王都的“修炉/运矿”是徭役；玩家可以被征召/逃避/替人服劳。

### 113. 朝贡 / tribute（帝国体系）【高】

- **做法**：小国/部落向大国定期送礼物/人/特产，换取承认/保护/贸易；朝贡不只是经济，也是礼仪/政治。
- **逻辑**：中心通过“收礼”确认自己的中心地位；边缘通过“送礼”换取安全。
- **可借**：新国要求旧地/矿区“朝贡”；玩家可以护送/抢劫/伪造贡品。

### 114. 和亲 / peace marriage（中国、欧洲等）【高】

- **做法**：两个国家/家族通过婚姻结盟；公主/贵族女被送到对方，嫁妆/聘礼/领土一起谈判。
- **逻辑**：婚姻是外交；女人的身体是条约的印章。
- **可借**：旧王/新国通过婚姻结盟；主角可能是和亲的产物/人质。

### 115. 质子 / hostage prince（罗马、日本、中国等）【高】

- **做法**：战败国/附属国把王子/贵族孩子送到宗主国，作为忠诚的保证；质子在当地长大/学习/被同化。
- **逻辑**：人质是“活的条约”；质子既是客人，也是刀下的人。
- **可借**：主角/某个 NPC 是质子；他的身份/忠诚被两边怀疑。

## 十、宗教、魔法与仪式

### 116. 萨满 / shamanism（西伯利亚、美洲、东亚等）【高】

- **做法**：萨满通过鼓/舞/药/禁食进入出神状态，灵魂出窍，去其他世界治病/找魂/问神。
- **逻辑**：可见世界只是世界的一半；疾病/灾难是“灵魂/关系”出了问题。
- **可借**：主角的梦是一场萨满之旅；他可以去“倒悬王都”找旧王的魂/记忆。

### 117. 附身 / possession（多地）【高】

- **做法**：神/灵/祖先进入人的身体，借人的口说话/治病/发怒；附身者可能失忆/抽搐/变声。
- **逻辑**：人的身体可以被“借用”；说话的不一定是本人。
- **可借**：回声/炉心借主角的身体说话；玩家要判断哪句话是旧王，哪句是主角自己。

### 118. 驱魔 / exorcism（多地）【高】

- **做法**：通过仪式/祷告/药/暴力把入侵的灵赶出身体/房子/地方。
- **逻辑**：疾病/疯狂是“外来者”造成的；赶走它，人就恢复。
- **可借**：王都的“死灵/矿石病”需要驱魔；玩家可以选择驱魔/超度/利用。

### 119. 朝圣 / pilgrimage（伊斯兰教、基督教、印度教等）【高】

- **做法**：信徒长途旅行到圣地，完成特定仪式；朝圣者受到特殊保护/尊重。
- **逻辑**：身体的移动就是精神的转化；到达圣地，人就“重生”。
- **可借**：主角下潜到核心是一场朝圣；每一层是一个“站”。

### 120. 圣物 / relics（基督教、佛教等）【高】

- **做法**：圣人的骨头/衣服/物品被供奉，被认为有神力；朝圣者触摸/亲吻/带回家。
- **逻辑**：身体的一部分仍然“活着”；神圣可以通过物质传递。
- **可借**：旧王的骨头/面具/签名是圣物；不同阵营争抢/伪造。

### 121. 毁像 / iconoclasm（拜占庭、宗教改革等）【高】

- **做法**：运动/政权摧毁宗教图像/雕像，认为它们是偶像崇拜/政治威胁。
- **逻辑**：图像有力量；毁掉图像，就毁掉它所代表的人/神。
- **可借**：新国摧毁旧王的画像/四骑士像；玩家可以偷藏/修复/毁掉。

### 122. 无像 / aniconism（伊斯兰教、犹太教等）【高】

- **做法**：不制作/崇拜神的形象，用文字/几何/空的空间代替。
- **逻辑**：神不能被图像限制；空/文字比画像更神圣。
- **可借**：旧国的“神”没有脸；核心/炉心也没有脸，只有签名。

### 123. 神圣王权 / divine kingship（古埃及、日本、非洲等）【中】

- **做法**：国王被视为神/神的化身/天地的中介；国王的健康/行为影响收成/灾难。
- **逻辑**：王不是一个人，是一个“位置”；王死了/病了，整个国家都危险。
- **可借**：旧王不是神，但被“王”的位置吃掉；新国的“第一公民”把自己做成神。

### 124. 禁忌 / taboo（波利尼西亚、多地）【高】

- **做法**：某些人/物/地方/词被认为是“神圣/危险”的，不能碰/说/看；违反会带来灾难。
- **逻辑**：秩序靠“不能做”维持；禁忌把权力/危险隔开。
- **可借**：王都的“不能看/不能问/不能摘面具”；玩家违反会触发剧情。

### 125. 曼纳 / mana（波利尼西亚）【中】

- **做法**：某些人/物拥有超自然的“力量/效力”；首领/战士/圣物有 mana，凡人不能随便碰。
- **逻辑**：权力是一种可积累/可失去的物质；不是谁都能承受。
- **可借**：旧王的签名/炉心核心有“mana”；玩家接触会被烧伤/改变。

### 126. 占卜 / divination（多地）【高】

- **做法**：通过骨头/龟甲/牌/星/内脏/梦/随机打开的书，读取未来/神意。
- **逻辑**：世界有隐藏的秩序；随机/裂缝/异常是信息的入口。
- **可借**：玩家可以用“炉心骰子/骨牌”占卜；结果影响 NPC/剧情。

### 127. 神谕 / oracle（德尔菲、多地）【高】

- **做法**：神庙/祭司在出神/烟雾/水中说出模糊的预言；求问者自己解释。
- **逻辑**：预言越模糊，越不会错；权力在于“解释”。
- **可借**：核心/回声给主角一句模糊的话；玩家可以选择相信/曲解/拒绝。

### 128. 诅咒板 / curse tablets（希腊、罗马）【高】

- **做法**：把诅咒写在铅板/陶片上，折起来埋在地下/墓里/井里，请神/死者执行。
- **逻辑**：文字可以伤害人；把话交给地下世界，比当面说更有效。
- **可借**：玩家可以写/找诅咒板；名字/签名是诅咒的靶子。

### 129. 巫术指控 / witchcraft accusations（欧洲、非洲等）【高】

- **做法**：社区把疾病/死亡/不幸归咎于某个“巫师”，通过审判/私刑/驱逐处理。
- **逻辑**：灾难需要一个人来负责；巫师是“内部的替罪羊”。
- **可借**：坑沿镇爆发矿石病，有人被指为“引炉者”；玩家可以救/揭穿/利用。

### 130. 千禧年运动 / millenarian movements（多地）【高】

- **做法**：一群人相信世界即将终结/重生，放弃财产/劳动，等待/促成大事件。
- **逻辑**：现实太苦，末日是希望；运动可以带来动员/暴力/牺牲。
- **可借**：炉心崇拜者相信“炉心将醒/世界将重造”；玩家可以加入/阻止。

### 131. 秘仪 / mystery religions（古希腊、罗马等）【高】

- **做法**：只有入会者才能参加的仪式，秘密/禁忌/戏剧化的死亡-重生体验；入会者获得特殊身份/救赎。
- **逻辑**：秘密本身是力量；知道别人不知道的事，就属于“内部人”。
- **可借**：四骑士/旧王的“内部记录”只有通过仪式才能读；玩家可以选择入会。

### 132. 忏悔 / confession（基督教、佛教等）【高】

- **做法**：向神父/僧侣/神/公众说出自己的罪，接受惩罚/宽恕；秘密被记录/保密。
- **逻辑**：说出来，罪才被处理；听的人/机构获得权力。
- **可借**：核心/回声是“忏悔机器”；玩家可以选择说真话/撒谎/沉默。

### 133. 赎罪券 / indulgence（中世纪基督教）【高】

- **做法**：用钱/功德换取罪的减免/炼狱时间的缩短；教会发行“券”。
- **逻辑**：罪是债，可以用钱/功德还；救赎可以被买卖。
- **可借**：王都的“炉心券/通行证”可以用钱/人情/血买；谁在卖，谁在骗。

### 134. 炼狱 / purgatory（天主教）【高】

- **做法**：死后灵魂在炼狱中净化一段时间，再进天堂；活人可以通过祈祷/弥撒/钱缩短时间。
- **逻辑**：死亡不是立刻判决，有一个“等待/净化”的中间状态；活人还能帮忙。
- **可借**：王都就是一个“炼狱”；死者/旧王在等活人完成仪式。

### 135. 家神 / household gods（罗马、中国、印度等）【高】

- **做法**：每个家庭供奉自己的守护神/灶神/祖先，日常上香/供饭；搬家要带神。
- **逻辑**：家是一个小宇宙；神住在家里，保护/监视家人。
- **可借**：主角的“家”有一个炉神/旧王像；玩家可以供奉/打碎/替换。

### 136. 护身符 / amulets（多地）【高】

- **做法**：佩戴特定石头/文字/骨头/植物，防止邪恶/疾病/厄运；护身符需要祝福/开光。
- **逻辑**：危险无处不在；一个小物件可以把危险挡在外面。
- **可借**：主角的身份牌/面具/戒指是护身符；摘下来就会“被看见”。

## 十二、怎么用

1. **先选“逻辑”，再换“表面”。** 比如“乳亲”的逻辑是“共同吃过的东西=亲属”，你可以换成“共同喝过炉水/共同吸过矿尘”。
2. **每条风俗都要有阶级版本。** 富人/穷人/旧国/新国/孤儿对同一件事的做法不同。
3. **让玩家撞见，不要一次性解释。** 先看见异常，再听 NPC 解释，最后用新证据修正。
4. **不要把真实神圣实践当装饰。** 天葬、寂静之塔、假面舞会、海吉拉等，借逻辑，换语境。
5. **标注可信度。** 写进游戏前，把 `【中】/【待核】` 再查一次；不要拿“听说”当民族志。
