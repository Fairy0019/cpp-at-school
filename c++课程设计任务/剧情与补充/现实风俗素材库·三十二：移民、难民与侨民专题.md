# 现实风俗素材库·三十二：移民、难民与侨民专题

> 状态：素材收集 v0.1，2026-11-26。
>
> 用途：收现代移民/难民/侨民的制度与生活，每条给“具体地区/群体 + 做法 + 逻辑 + 可借 + 出处”。
>
> 说明：
> - 这一卷涉及边境/战争/贫困/歧视，写作时不要猎奇；借制度逻辑，不借痛苦表面。
> - 出处以 UN/UNHCR/历史研究/新闻为主；百科只当入口。
> - `【高】` = 学术/UN 来源较可靠；`【中】` = 来源较泛，写进游戏前再核；`【待核】` = 只当线索。

## 七、怎么用

1. **先看具体地区/群体**：不要写“移民……”，写“美墨边境/地中海/罗兴亚/土耳其裔德国人……”。
2. **再看“谁在讲/谁受益”**：国家/蛇头/NGO/雇主/侨民都在争解释权。
3. **借逻辑，不借表面**：边境→炉墙；营地→炉营；蛇头→炉路；汇款→炉钱；二代→炉民。
4. **标注可信度**：`【中】/【待核】` 的条目，写进游戏前再查。
5. **不要猎奇**：边境/营地/偷渡/贩运，背后是真实的人；写制度，不写“奇观”。
