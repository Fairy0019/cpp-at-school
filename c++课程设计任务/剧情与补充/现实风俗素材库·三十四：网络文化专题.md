# 现实风俗素材库·三十四：网络文化专题

> 状态：素材收集 v0.1，2026-11-26。
>
> 用途：收 21 世纪网络文化/平台/社群，每条给“具体平台/案例 + 做法 + 逻辑 + 可借 + 出处”。
>
> 说明：
> - 这一卷偏“数字民俗/平台文化”，不是传统民俗；但同样是“人怎么说话/聚会/造神/传谣”的素材。
> - 出处以媒体研究/平台报告/新闻为主；百科只当入口。
> - `【高】` = 学术/平台报告较可靠；`【中】` = 来源较泛，写进游戏前再核；`【待核】` = 只当线索。
> - 涉及阴谋论/骚扰/极端内容，写作时不要猎奇；写机制，不写“奇观”。

- **做法**：柴犬照片/ Comic Sans/ 破碎英语/“such wow”/币圈/ NFT；从玩笑到资本；谁用/谁改，代表圈层/时代。

## 七、怎么用

1. **先看具体平台/案例**：不要写“网民……”，写“4chan/Twitch/ TikTok/ QAnon……”。
2. **再看“谁在讲/谁受益”**：平台/资本/国家/社群都在争解释权。
3. **借逻辑，不借表面**：迷因→炉梗；直播→炉播；算法→炉眼；阴谋→炉谣；深伪→炉影。
4. **标注可信度**：`【中】/【待核】` 的条目，写进游戏前再查。
5. **不要猎奇**：阴谋/骚扰/极端内容，背后是真实的人；写机制，不写“奇观”。
